# Thuật toán GTS2 (Greedy Traveling Salesman)
**Input:**  
$n$, $c$, $p$; $v_i$ $(i = 1...p)$ // $v_i$ là các thành phố cho trước hoặc cũng có thể được chọn ngẫu nhiên trong tập $1..p$
**Output:**  
$besttour$, $bestcost$
```text
bestcost = 0;
besttour = {};
for i = 1 to p
{
    GTS1(vk); // suy ra được tour(vk) và cost(vk)
    if cost(vk) < bestcost
    {
        bestcost = cost(vk);
        besttour = tour(vk);
    }
}

```
