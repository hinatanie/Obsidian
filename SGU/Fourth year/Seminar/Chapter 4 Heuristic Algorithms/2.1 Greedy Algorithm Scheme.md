# Lược đồ thuật toán tham lam
```text
void Greedy(A, S) // A là tập các ứng cử viên, S là tập nghiệm
{
    S = ∅;
    while (A ≠ ∅)
    {
        x = select(A);   // chọn phần tử tốt nhất trong A
        A = A - {x};
        if (S ∪ {x} chấp nhận được)
            S = S ∪ {x};
    }
    Trả về S;
}
```
