# Ví dụ về việc xây dựng đồ thị tăng luồng
**Thí dụ:** Các số viết cạnh các cung của $G$ ở hình 1 theo thứ tự là khả năng thông qua và lượng trên cung.
**Mạng $G$ và luồng $f$. Đồ thị có trọng số $G_f$ tương ứng.**


```
Mạng G và luồng f:
                 s
              ↙     ↘
          3,3         1,4
           ↓           ↓
           b ←──0,1─── c
           │  \         │
         2,3  \2,2      │0,3
           │    \       │
           ↓     ↘      ↓
           d             e
            \           /
          2,4\         /2,3
              \       /
                 t
```

Các cung của mạng `G`:
```
s → b : 3,3
s → c : 1,4
c → b : 0,1
b → d : 2,3
b → e : 2,2
c → e : 0,3
d → t : 2,4
e → t : 2,3
```
