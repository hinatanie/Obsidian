Spring Boot trong kiến trúc client server
- Cách sử dụng Spring với các tệp tĩnh (HTML/JS) cho frontend
- cung cấp dữ liệu qua API cho backend

- sử dụng annotation @RestController, @RequestMapping để xây dựng RESTful Web Service 
- cơ chế Spring Boot tự động chuyển đổi sang Java Object sang định dạng JSON để phản hồi cho client


-  khái niệm CORS, điểm quan trọng khi phát triển dự án tách biệt frontend và backend
- Cách cấu hình CORS trong Spring Boot để một ứng dụng React và Angular truy cập vào API

- Trong trường hợp không tách biệt hoàn toàn frontend, cách Spring Boot hỗ trợ template engines như Thymeleaf để render giao diện trực tiếp từ phía server
- Ưu điểm và nhược điểm của cách tiếp cận khi sử dụng các template này, không tách biệt frontend so với việc dùng Single Page Application (SPA)
- khái niệm SPA
