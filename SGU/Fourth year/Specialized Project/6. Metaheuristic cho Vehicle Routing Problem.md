# Metaheuristic cho Vehicle Routing Problem
Đây là đề tài **dễ hiểu và dễ triển khai nhất trong 4 cái**.
## Bài toán
Bạn có:
```
                    Depot
                      D
              /       |       \
             /        |        \
           C1        C2        C3
       C4         C5        C6
```
Có:
- 1 kho hàng
- nhiều khách hàng
- nhiều xe
Bạn cần tìm:
```
Xe 1: Depot → C1 → C4 → C2 → Depot
Xe 2: Depot → C3 → C5 → C6 → Depot
```
sao cho tổng quãng đường nhỏ nhất.
Ví dụ hàm mục tiêu:
```
Minimize:
total_distance
```
hoặc phức tạp hơn:
```
Minimize:
distance
+ delivery_delay
+ fuel_cost
```

---
## Bạn sẽ làm gì?
### Bước 1 — Học VRP
Trước tiên hiểu:
```
TSP
 ↓
VRP
 ↓
CVRP
 ↓
VRPTW
```
Tôi khuyên bạn chọn:
> **Capacitated Vehicle Routing Problem — CVRP**
Vì đủ khó để làm nghiên cứu nhưng chưa quá phức tạp.

---
### Bước 2 — Biểu diễn lời giải
Ví dụ có 6 khách:
```
[1, 4, 2 | 3, 5, 6]
```
nghĩa là:
```
Vehicle 1
D → 1 → 4 → 2 → D
Vehicle 2
D → 3 → 5 → 6 → D
```

---
### Bước 3 — Chọn Metaheuristic
Ví dụ Genetic Algorithm.
```
Population
Solution A
[1 4 2 | 3 5 6]
Solution B
[2 1 5 | 3 4 6]
Solution C
[6 4 1 | 2 3 5]
```
Sau đó:
```
Selection
Crossover
Mutation
Selection
...
```
Sau 500–1000 generations:
```
Best route
```
