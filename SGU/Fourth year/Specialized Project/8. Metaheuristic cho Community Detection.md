# Metaheuristic cho Community Detection
Đây là bài toán:
> Tìm các nhóm người tự nhiên trong mạng xã hội.
Ví dụ:
```
  A──B
  |\ |
  C──D
        E──F
        |\ |
        G──H
```
Thuật toán nên phát hiện:
```
Community 1
A B C D
Community 2
E F G H
```

---
## Mục tiêu
Bạn cần chia graph thành:
```
C1
C2
C3
...
```
sao cho:
```
nhiều cạnh bên trong community
ít cạnh giữa các community
```
Metric phổ biến nhất:
```
Modularity Q
```
Mục tiêu:
```
maximize Q
```

---
## Biểu diễn solution
Ví dụ:
```
Node
A B C D E F G H
Community
1 1 1 1 2 2 2 2
```
Genetic Algorithm có thể thay đổi assignment này.
Ví dụ mutation:
```
Before
A → Community 1
After
A → Community 2
```
Sau đó đo lại modularity.
