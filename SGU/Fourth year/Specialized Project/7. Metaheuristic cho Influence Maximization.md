# Metaheuristic cho Influence Maximization
Đề tài này liên quan đến mạng xã hội.
Ví dụ:
```
      A
    / | \
   B  C  D
  /      / \
 E      F   G
```
Bạn chỉ được chọn **2 người** để quảng bá sản phẩm.
Chọn:
```
A + D
```
có thể lan truyền tới:
```
A → B
A → C
A → D
D → F
D → G
```
Tổng:
```
7 users influenced
```

---
## Bài toán
Cho graph:
```
G = (V, E)
```
Tìm:
```
k nodes
```
sao cho:
```
InfluenceSpread(S)
```
lớn nhất.
Nói dễ hiểu:
> Chọn K người có khả năng khiến nhiều người khác bị ảnh hưởng nhất.

---
## Bạn cần học thêm
Hai mô hình lan truyền phổ biến:
```
Independent Cascade Model
Linear Threshold Model
```
Ví dụ IC:
```
A → B
probability = 0.3
```
A có 30% khả năng ảnh hưởng B.

---
## Metaheuristic
Ví dụ Genetic Algorithm:
```
Solution:
[A, D, H, K, P]
```
nghĩa là chọn 5 người làm seed.
Fitness:
```
fitness =
expected number of influenced users
```
Bạn chạy simulation nhiều lần:
```
100
500
1000 Monte Carlo simulations
```
để ước lượng influence spread.
