# Metaheuristic để ngăn chặn misinformation
Đề tài này phức tạp nhất.
Ví dụ mạng:
```
Fake news source
       A
      / \
     B   C
    /     \
   D       E
```
Tin giả đang lan:
```
A
↓
B C
↓
D E
```
Bạn được phép chọn:
```
k users
```
để phát thông tin đúng hoặc chặn lan truyền.
Ví dụ chọn:
```
B
C
```
thì:
```
Fake news
   A
  / \
 X   X
B và C được immunize
```
Tin giả không lan xuống nữa.

---
## Bài toán
Tìm tập:
```
S ⊂ V

|S| = k
```
sao cho:
```
minimize misinformation spread
```
hoặc:
```
maximize number of protected users
```

---
## Metaheuristic
Một solution:
```
[B, C, H, K, M]
```
nghĩa là:
```
5 users được chọn để counter misinformation
```
Fitness:
```
fitness =
number of users protected
```

```
GA
PSO
GWO
SA
```
