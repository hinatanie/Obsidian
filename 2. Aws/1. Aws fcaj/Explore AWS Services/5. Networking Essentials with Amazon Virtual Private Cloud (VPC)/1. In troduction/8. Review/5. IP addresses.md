##### **What is Amazon VPC?**
?  
+++  
[#flashcards](#flashcards)  
`Amazon VPC` means `Amazon Virtual Private Cloud`.  
Amazon VPC lets you create your own private, controlled, and secure network inside AWS.  
Normally, if you run servers in a company data center, you need to design the network yourself.  
For example:
```
IP addresses
Subnets
Routing
Gateways
Security
```
Amazon VPC gives you the same kind of control, but inside the AWS Cloud.  
**Simple idea**  
A `VPC` is like your own private network inside AWS.  
Inside that network, you can run resources like:
```
EC2 servers
Databases
Load balancers
Containers
```
You control how those resources connect to each other and to the internet.

###### **What is a VPC CIDR block?**
?  
+++  
[#flashcards](#flashcards)  
When you create a VPC, you choose an IP address range.  
For example:
```
10.0.0.0/16
```
This range is called a `CIDR block`.  
The CIDR block decides what private IP addresses can exist inside your VPC.  
?  
+++  
[#flashcards](#flashcards)
###### **What does `10.0.0.0/16` mean?**
?  
+++  
[#flashcards](#flashcards)
```
10.0.0.0/16
```
This means your VPC can use IP addresses from the `10.0.x.x` range.  
For example:
```
10.0.1.10
10.0.2.25
10.0.100.50
```
A `/16` CIDR block gives a large number of IP addresses.  
?  
+++  
[#flashcards](#flashcards)
###### **What does CIDR block size mean?**
?  
+++  
[#flashcards](#flashcards)  
The CIDR block size controls how many IP addresses your VPC can have.  
For example:
```
/16 means 65,536 IP addresses
/28 means 16 IP addresses
```
A smaller number after `/` means a bigger network.  
A bigger number after `/` means a smaller network.

###### **What is IPv4?**
?  
+++  
[#flashcards](#flashcards)  
`IPv4` is the older and most common IP address system.  
Example IPv4 address:
```
192.168.1.1
```
Most common private network ranges use IPv4.

###### **What is IPv6?**
?  
+++  
[#flashcards](#flashcards)  
`IPv6` is a newer IP address system with a much larger address space.  
IPv6 addresses are longer than IPv4 addresses.  
?  
+++

###### **What is a primary CIDR block?**
?  
+++  
[#flashcards](#flashcards)  
A `primary CIDR block` is the main IP address range assigned to a VPC when it is created.  
Example:
```
10.0.0.0/16
```
This is the main private IP range for the VPC.  
?  
+++  
[#flashcards](#flashcards)
###### **What is a CIDR block?**
?  
+++  
[#flashcards](#flashcards)  
A `CIDR block` is an IP address range.  
It can be used by:
```
VPC
Subnet
Network
```
Example:
```
10.0.0.0/16
```
or:
```
10.0.1.0/24
```
?  
+++  
[#flashcards](#flashcards)
###### **What is subnet sizing?**
?  
+++  
[#flashcards](#flashcards)  
`Subnet sizing` means choosing how large a subnet should be.  
You choose the subnet size by selecting a CIDR block.  
For example:
```
10.0.1.0/24
```
A `/24` subnet gives 256 IP addresses.  
You should choose subnet sizes carefully so you have enough IP addresses for your resources.  
?  
+++  
[#flashcards](#flashcards)
###### **What is a private IP address?**
?  
+++  
[#flashcards](#flashcards)  
A `private IP address` is an internal IP address used inside a private network.  
Example:
```
10.0.1.20
```
Private IP addresses are used for communication inside the VPC.  
They are not directly reachable from the public internet.  
?  
+++  
[#flashcards](#flashcards)
###### **What is a public IP address?**
?  
+++  
[#flashcards](#flashcards)  
A `public IP address` is an IP address that can be used on the public internet.  
If an EC2 instance has a public IP address and the correct routing/security settings, people from the internet can reach it.  
?  
+++  
[#flashcards](#flashcards)
###### **What is an Elastic IP address?**
?  
+++  
[#flashcards](#flashcards)  
An `Elastic IP address` is a static public IP address that you can allocate in AWS and attach to resources.  
Unlike a normal public IP address, an Elastic IP can stay the same.  
For example, you can attach it to an EC2 instance or a NAT Gateway.  
?  
+++  
[#flashcards](#flashcards)
###### **What is source IP?**
?  
+++  
[#flashcards](#flashcards)  
`Source IP` is the IP address where traffic comes from.  
For example:
```
User IP → Web server
```
The user's IP address is the source IP.  
?  
+++  
[#flashcards](#flashcards)
###### **What is Network Address Translation?**
?  
+++  
[#flashcards](#flashcards)  
`Network Address Translation`, or `NAT`, means changing one IP address into another IP address when traffic moves between networks.  
For example, a private EC2 instance may use a NAT Gateway to access the internet.  
The internet sees the NAT Gateway's public IP address, not the private EC2 instance's private IP address.
