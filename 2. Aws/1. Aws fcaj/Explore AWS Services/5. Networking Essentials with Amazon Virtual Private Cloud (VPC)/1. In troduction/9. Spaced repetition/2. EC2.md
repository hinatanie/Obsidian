##### **What is Amazon VPC?**
?  
+++  
[#flashcards](#flashcards)  
`Amazon VPC` means `Amazon Virtual Private Cloud`.  
Amazon VPC lets you create your own private, controlled, and secure network inside AWS.  
Normally, if you run servers in a company data center, you need to design the network yourself.  
For example:
```
IP addresses
Subnets
Routing
Gateways
Security
```
Amazon VPC gives you the same kind of control, but inside the AWS Cloud.  
**Simple idea**  
A `VPC` is like your own private network inside AWS.  
Inside that network, you can run resources like:
```
EC2 servers
Databases
Load balancers
Containers
```
You control how those resources connect to each other and to the internet.  
?  
+++  
[#flashcards](#flashcards)
###### **What came before Amazon VPC?**
?  
+++  
[#flashcards](#flashcards)  
Amazon VPC came after Amazon EC2.  
In the past, AWS had two networking models:
```
EC2-Classic
EC2-VPC
```
?  
+++  
[#flashcards](#flashcards)
###### **What was EC2-Classic?**
?  
+++  
[#flashcards](#flashcards)  
`EC2-Classic` was the old AWS networking model.  
In this model, resources used a shared, flat network.  
That means EC2 instances were not running inside your own private VPC.  
Many AWS customers used the shared AWS network model.  
?  
+++  
[#flashcards](#flashcards)
###### **What is EC2-VPC?**
?  
+++  
[#flashcards](#flashcards)  
`EC2-VPC` is the current AWS networking model.  
In this model, resources run inside isolated virtual networks.  
That virtual network is your VPC.  
This is more secure and gives you more control.  
?  
+++  
[#flashcards](#flashcards)
###### **What is a NAT Gateway?**
?  
+++  
[#flashcards](#flashcards)  
A `NAT Gateway` allows private resources to access the internet without allowing the internet to directly access them.  
For example, an EC2 instance in a private subnet may need to download software updates.  
It can use a NAT Gateway for outbound internet access.  
But people from the internet cannot directly connect to that private EC2 instance.  
?  
+++  
[#flashcards](#flashcards)
###### **What is Amazon EC2?**
?  
+++  
[#flashcards](#flashcards)  
`Amazon EC2` is a service that lets you create and run virtual servers in AWS.  
An EC2 instance is like a server in the cloud.  
You can install applications, databases, or backend services on it.  
?  
+++  
[#flashcards](#flashcards)
###### **What is a shared network?**
?  
+++  
[#flashcards](#flashcards)  
A `shared network` is a network used by many customers or systems together.  
EC2-Classic used a shared network model in the past.  
VPC is better because it gives each customer isolated network control.  
?  
+++  
[#flashcards](#flashcards)
###### **What is internet-bound traffic?**
?
+++  
[#flashcards](#flashcards)  
`Internet-bound traffic` is traffic going to the internet.  
For example:
```
Private EC2 instance → NAT Gateway → Internet
```
This is outbound traffic from your VPC to the internet.  
?  
+++  
[#flashcards](#flashcards)
###### **What is a public IP address?**
?  
+++  
[#flashcards](#flashcards)  
A `public IP address` is an IP address that can be used on the public internet.  
If an EC2 instance has a public IP address and the correct routing/security settings, people from the internet can reach it.  
?  
+++  
[#flashcards](#flashcards)
###### **What is an Elastic IP address?**
?  
+++  
[#flashcards](#flashcards)  
An `Elastic IP address` is a static public IP address that you can allocate in AWS and attach to resources.  
Unlike a normal public IP address, an Elastic IP can stay the same.  
For example, you can attach it to an EC2 instance or a NAT Gateway.  
?  
+++  
[#flashcards](#flashcards)
###### **What is Network Address Translation?**
?  
+++  
[#flashcards](#flashcards)  
`Network Address Translation`, or `NAT`, means changing one IP address into another IP address when traffic moves between networks.  
For example, a private EC2 instance may use a NAT Gateway to access the internet.  
The internet sees the NAT Gateway's public IP address, not the private EC2 instance's private IP address.  
?  
+++  
[#flashcards](#flashcards)
###### **What is outbound traffic?**
?  
+++  
[#flashcards](#flashcards)  
`Outbound traffic` is traffic going out from your VPC to the internet or another network.  
Example:
```
EC2 instance → Internet
```
?  
+++  
[#flashcards](#flashcards)
###### **What is a NAT Instance?**
?  
+++  
[#flashcards](#flashcards)  
A `NAT Instance` is an EC2 instance manually configured to perform NAT.  
You manage it yourself.  
Compared with a NAT Gateway, a NAT Instance gives more control but requires more maintenance.  
?
