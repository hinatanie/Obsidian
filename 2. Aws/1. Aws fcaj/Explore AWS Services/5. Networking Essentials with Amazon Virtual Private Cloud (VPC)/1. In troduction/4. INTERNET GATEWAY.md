creating an Internet Gateway and your subnet route table must have a rule like this and **EC2 must have public IP or Elastic IP** to access the internet
```
Destination: 0.0.0.0/0
Target: Internet Gateway
```

An EC2 instance usually knows its private IP only
Example public subnet route table
```
Destination    Target
10.0.0.0/16    local
0.0.0.0/0      Internet Gateway
```
Your EC2 has a private IP inside AWS but people on the internet cannot use that private IP so AWS gives the EC2 a public IP

When this EC2 sends traffic to the internet, the Internet Gateway changes the source IP
```
Before leaving VPC
Source IP: 10.0.1.10

After passing IGW
Source IP: 54.12.34.56
```
This process is called Network Address Translation or NAT

So the flow is EC2 private IP 10.0.1.10 is directed to Internet Gateway and the IP is changed in public IP 54.20.30.40

---

When user send request to a public IP, inside the VPC, the EC2 is known by private IP so internet Gateway helps translate public IP to private IP
