What is Amazon VPC?

The answer is that `Amazon VPC` means `Amazon Virtual Private Cloud`, and it lets you create your own private, controlled, and secure network inside AWS. Like a network in a company data center, it gives you control over IP addresses, subnets, routing, gateways, and security. Inside a VPC, you can run resources such as EC2 servers, databases, load balancers, and containers, and control how they connect to each other and to the internet.

What is a public subnet?

The answer is that a `public subnet` is a subnet that can connect to the internet through an `Internet Gateway`. It is usually used for internet-facing resources such as web servers, load balancers, and bastion hosts.

What is a private subnet?

The answer is that a `private subnet` is a subnet that is not directly reachable from the public internet. It is usually used for internal resources such as databases, private backend services, and internal application servers. Private resources can still access the internet through a `NAT Gateway`, but the internet cannot directly access them.

What is the default VPC?

The answer is that AWS creates a default VPC in each Region using the CIDR block `172.31.0.0/16`. The default VPC is useful for learning and quick testing, but production systems usually use a custom VPC for better control over IP ranges, subnets, routing, gateways, security, and network architecture. Important VPC components include subnets, route tables, Internet Gateways, and NAT Gateways, which control how traffic moves inside and outside the VPC.

What is a route table?

The answer is that a `route table` is a set of rules that tells network traffic where to go. For example, it can direct internet traffic to an `Internet Gateway`, traffic inside the VPC to the local route, and traffic to a private network through a VPN Gateway. Route tables control network paths.

What is a gateway?

The answer is that a `gateway` is a connection point between networks. In AWS, gateways help a VPC connect to the internet, another private network, or an on-premises network.

What is an Internet Gateway?

The answer is that an `Internet Gateway` is a VPC component that allows resources in public subnets to access the internet and allows internet traffic to reach public resources in the VPC. For example, a public EC2 web server needs an Internet Gateway to be reachable from the internet.

What is a NAT Gateway?

The answer is that a `NAT Gateway` allows private resources to access the internet without allowing the internet to connect to them directly. For example, an EC2 instance in a private subnet can use a NAT Gateway to download software updates, but people on the internet cannot directly reach that instance.

What is a Virtual Private Gateway?

The answer is that a `Virtual Private Gateway`, or `VGW`, is a gateway used to connect a VPC to another private network. It is often used with a VPN connection to link an on-premises company network to an AWS VPC.

What is internet-bound traffic?

The answer is that `internet-bound traffic` is traffic going from a VPC to the internet. For example, a private EC2 instance may send outbound traffic through a NAT Gateway before it reaches the internet.

What is network architecture?

The answer is that `network architecture` is the overall design of how a network is organized. It includes VPCs, subnets, route tables, gateways, security groups, CIDR blocks, and traffic flow. Good network architecture makes a system more secure and easier to manage.

What is a VPC component?

The answer is that a `VPC component` is a networking part located inside or attached to a VPC. Examples include a subnet, route table, Internet Gateway, NAT Gateway, security group, and Network ACL.

What is an Elastic IP address?

The answer is that an `Elastic IP address` is a static public IP address that you can allocate in AWS and attach to a resource. Unlike a normal public IP address, it can remain the same and can be attached to an EC2 instance or a NAT Gateway.

What is Network Address Translation?

The answer is that `Network Address Translation`, or `NAT`, changes one IP address into another when traffic moves between networks. For example, when a private EC2 instance uses a NAT Gateway to access the internet, the internet sees the NAT Gateway’s public IP address instead of the instance’s private IP address.

What is a NAT Instance?

The answer is that a `NAT Instance` is an EC2 instance that is manually configured to perform NAT. You manage it yourself, and although it gives you more control than a NAT Gateway, it also requires more maintenance.

What is a protocol?

The answer is that a `protocol` is a communication method that defines how computers communicate with each other. Examples include `HTTP`, `HTTPS`, `TCP`, `UDP`, `ICMP`, and `SSH`. In a common VPC design, a VPC may use `10.0.0.0/16`, with a public subnet such as `10.0.1.0/24` containing a web server and load balancer, and a private subnet such as `10.0.2.0/24` containing a backend server and database. An `Internet Gateway` allows the public subnet to access the internet, while a `NAT Gateway` allows the private subnet to access the internet safely. A `VPC` is a private network inside AWS, a `CIDR block` is its IP range, a `subnet` is a smaller network inside the VPC, and a `route table` controls where traffic goes. For production, you usually create a custom VPC instead of relying only on the default VPC.
