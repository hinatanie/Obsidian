What is Amazon VPC?

The answer is that `Amazon VPC` means `Amazon Virtual Private Cloud`, and it lets you create your own private, controlled, and secure network inside AWS. Like a network in a company data center, it gives you control over IP addresses, subnets, routing, gateways, and security. Inside a VPC, you can run resources such as EC2 servers, databases, load balancers, and containers, and control how they connect to each other and to the internet.

What is a VPC CIDR block?

The answer is that when you create a VPC, you choose an IP address range, such as `10.0.0.0/16`. This range is called a `CIDR block`, and it determines which private IP addresses can exist inside your VPC.

What does `10.0.0.0/16` mean?

The answer is that `10.0.0.0/16` allows your VPC to use IP addresses in the `10.0.x.x` range, such as `10.0.1.10`, `10.0.2.25`, and `10.0.100.50`. A `/16` CIDR block provides a large number of IP addresses.

What does CIDR block size mean?

The answer is that CIDR block size controls how many IP addresses a VPC can have. For example, `/16` represents 65,536 IP addresses, while `/28` represents 16 IP addresses. A smaller number after the `/` means a larger network, while a larger number means a smaller network.

What is IPv4?

The answer is that `IPv4` is the older and most common IP address system. An example of an IPv4 address is `192.168.1.1`, and most common private network ranges use IPv4.

What is IPv6?

The answer is that `IPv6` is a newer IP address system with a much larger address space, and its addresses are longer than IPv4 addresses.

What is a primary CIDR block?

The answer is that a `primary CIDR block` is the main IP address range assigned to a VPC when it is created. For example, `10.0.0.0/16` can be the main private IP range for a VPC.

What is a CIDR block?

The answer is that a `CIDR block` is an IP address range that can be used by a VPC, subnet, or network. Examples include `10.0.0.0/16` and `10.0.1.0/24`.

What is subnet sizing?

The answer is that `subnet sizing` means choosing how large a subnet should be by selecting a CIDR block. For example, a subnet using `10.0.1.0/24` provides 256 IP addresses. You should choose subnet sizes carefully so that you have enough IP addresses for your resources.

What is a private IP address?

The answer is that a `private IP address` is an internal IP address used for communication inside a private network such as a VPC. For example, `10.0.1.20` is a private IP address and is not directly reachable from the public internet.

What is a public IP address?

The answer is that a `public IP address` is an IP address that can be used on the public internet. If an EC2 instance has a public IP address and the correct routing and security settings, people on the internet can reach it.

What is an Elastic IP address?

The answer is that an `Elastic IP address` is a static public IP address that you can allocate in AWS and attach to a resource. Unlike a normal public IP address, it can remain the same and can be attached to an EC2 instance or a NAT Gateway.

What is source IP?

The answer is that `source IP` is the IP address from which traffic originates. For example, when a user sends traffic to a web server, the user’s IP address is the source IP.

What is Network Address Translation?

The answer is that `Network Address Translation`, or `NAT`, changes one IP address into another when traffic moves between networks. For example, when a private EC2 instance uses a NAT Gateway to access the internet, the internet sees the NAT Gateway’s public IP address instead of the instance’s private IP address.
