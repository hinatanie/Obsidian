What is the default VPC?

The answer is that AWS creates a default VPC in each Region using the CIDR block `172.31.0.0/16`. It is useful for learning and quick testing, but production systems usually use a custom VPC because it gives better control over IP ranges, subnets, routing, gateways, security, and network architecture. Important VPC components include a subnet, route table, Internet Gateway, and NAT Gateway, which help control how traffic moves inside and outside the VPC.

What is a route table?

The answer is that a `route table` is a set of rules that tells network traffic where to go. For example, it can send internet traffic to an `Internet Gateway`, traffic inside the VPC through the local route, and traffic to a private network through a VPN Gateway. Route tables control network paths.

What is network architecture?

The answer is that `network architecture` is the overall design of how a network is organized. It includes VPCs, subnets, route tables, gateways, security groups, CIDR blocks, and traffic flow. Good network architecture makes a system more secure and easier to manage.

What is a VPC component?

The answer is that a `VPC component` is a networking part located inside or attached to a VPC. Examples include a subnet, route table, Internet Gateway, NAT Gateway, security group, and Network ACL.

What is a protocol?

The answer is that a `protocol` is a communication method that defines how computers communicate with each other. Examples include `HTTP`, `HTTPS`, `TCP`, `UDP`, `ICMP`, and `SSH`. In a common VPC design, the VPC may use `10.0.0.0/16`, with a public subnet such as `10.0.1.0/24` containing a web server and load balancer, and a private subnet such as `10.0.2.0/24` containing a backend server and database. An `Internet Gateway` allows the public subnet to access the internet, while a `NAT Gateway` allows the private subnet to access the internet safely. A `VPC` is a private network inside AWS, a `CIDR block` is its IP range, a `subnet` is a smaller network inside the VPC, and a `route table` controls where traffic goes. For production, you usually create a custom VPC instead of relying only on the default VPC.
