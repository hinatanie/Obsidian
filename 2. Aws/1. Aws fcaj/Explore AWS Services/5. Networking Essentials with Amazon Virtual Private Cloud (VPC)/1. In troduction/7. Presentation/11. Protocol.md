What is a protocol?

The answer is that a `protocol` is a communication method that defines how computers communicate with each other. Examples include `HTTP`, `HTTPS`, `TCP`, `UDP`, `ICMP`, and `SSH`. In a common VPC design, the VPC may use `10.0.0.0/16`, with a public subnet such as `10.0.1.0/24` containing a web server and load balancer, and a private subnet such as `10.0.2.0/24` containing a backend server and database. An `Internet Gateway` allows the public subnet to access the internet, while a `NAT Gateway` allows the private subnet to access the internet safely. A `VPC` is a private network inside AWS, a `CIDR block` is its IP range, a `subnet` is a smaller network inside the VPC, and a `route table` controls where traffic goes. For production, you usually create a custom VPC instead of relying only on the default VPC.
