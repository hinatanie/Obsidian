##### What is Amazon VPC?

The answer is that `Amazon VPC` means `Amazon Virtual Private Cloud`, and it lets you create your own private, controlled, and secure network inside AWS. Like a network in a company data center, it gives you control over IP addresses, subnets, routing, gateways, and security. Inside a VPC, you can run resources such as EC2 servers, databases, load balancers, and containers, and control how they connect to each other and to the internet.

##### What came before Amazon VPC?

The answer is that Amazon VPC came after Amazon EC2. In the past, AWS had two networking models called `EC2-Classic` and `EC2-VPC`.

##### What was EC2-Classic?

The answer is that `EC2-Classic` was the old AWS networking model in which resources used a shared, flat network instead of running inside a private VPC.

##### What is EC2-VPC?

The answer is that `EC2-VPC` is the current AWS networking model in which resources run inside isolated virtual networks called VPCs. This model is more secure and gives you more control.

##### What is a NAT Gateway?

The answer is that a `NAT Gateway` allows private resources to access the internet without allowing the internet to connect to them directly. For example, an EC2 instance in a private subnet can use a NAT Gateway to download software updates, but people on the internet cannot directly reach that instance.

##### What is Amazon EC2?

The answer is that `Amazon EC2` is a service that lets you create and run virtual servers in AWS. An EC2 instance is like a server in the cloud, and you can install applications, databases, or backend services on it.

##### What is a shared network?

The answer is that a `shared network` is a network used by many customers or systems together. `EC2-Classic` used this model, while a VPC gives each customer isolated network control.

##### What is internet-bound traffic?

The answer is that `internet-bound traffic` is traffic going from your VPC to the internet. For example, a private EC2 instance may send traffic through a NAT Gateway to reach the internet.

##### What is a public IP address?

The answer is that a `public IP address` is an IP address that can be used on the public internet. If an EC2 instance has a public IP address and the correct routing and security settings, people on the internet can reach it.

##### What is an Elastic IP address?

The answer is that an `Elastic IP address` is a static public IP address that you can allocate in AWS and attach to a resource. Unlike a normal public IP address, it can remain the same and can be attached to an EC2 instance or a NAT Gateway.

##### What is Network Address Translation?

The answer is that `Network Address Translation`, or `NAT`, changes one IP address into another when traffic moves between networks. For example, when a private EC2 instance uses a NAT Gateway to access the internet, the internet sees the NAT Gateway’s public IP address instead of the instance’s private IP address.

##### What is outbound traffic?

The answer is that `outbound traffic` is traffic going out from your VPC to the internet or another network, such as traffic sent from an EC2 instance to the internet.

##### What is a NAT Instance?

The answer is that a `NAT Instance` is an EC2 instance that is manually configured to perform NAT. You manage it yourself, and although it gives you more control than a NAT Gateway, it also requires more maintenance.
