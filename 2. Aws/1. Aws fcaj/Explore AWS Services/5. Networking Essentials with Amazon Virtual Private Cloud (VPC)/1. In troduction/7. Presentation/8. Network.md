What is Amazon VPC?

The answer is that `Amazon VPC` means `Amazon Virtual Private Cloud`, and it lets you create your own private, controlled, and secure network inside AWS. Like a network in a company data center, it gives you control over IP addresses, subnets, routing, gateways, and security. Inside a VPC, you can run resources such as EC2 servers, databases, load balancers, and containers, and control how they connect to each other and to the internet.

What is a subnet?

The answer is that a `subnet` is a smaller network inside a VPC that helps organize resources. For example, a VPC using `10.0.0.0/16` can be divided into a public subnet using `10.0.1.0/24` for web servers and a private subnet using `10.0.2.0/24` for databases. The VPC is the larger network, while the subnets are smaller parts inside it.

What does CIDR block size mean?

The answer is that CIDR block size controls how many IP addresses a VPC can have. For example, `/16` represents 65,536 IP addresses, while `/28` represents 16 IP addresses. A smaller number after the `/` means a larger network, while a larger number means a smaller network.

Why should VPC CIDR blocks not overlap?

The answer is that a VPC CIDR block should not overlap with the IP ranges of a company office network, VPN network, another VPC, or any other connected network because overlapping ranges make routing confusing. For example, if both a company network and an AWS VPC use `10.0.0.0/16`, the system may not know whether traffic for `10.0.1.20` belongs to the office network or the VPC. You should choose a different range, such as `10.10.0.0/16` or `172.16.0.0/16`.

What came before Amazon VPC?

The answer is that Amazon VPC came after Amazon EC2. In the past, AWS had two networking models called `EC2-Classic` and `EC2-VPC`.

What was EC2-Classic?

The answer is that `EC2-Classic` was the old AWS networking model in which many AWS customers used a shared, flat network. EC2 instances did not run inside each customer’s own private VPC.

What is EC2-VPC?

The answer is that `EC2-VPC` is the current AWS networking model in which resources run inside isolated virtual networks called VPCs. This model is more secure and gives you more control.

What is the default VPC?

The answer is that AWS creates a default VPC in each Region using the CIDR block `172.31.0.0/16`. It is useful for learning and quick testing, but production systems usually use a custom VPC because it gives better control over IP ranges, subnets, routing, gateways, security, and network architecture. Important VPC components include a subnet, route table, Internet Gateway, and NAT Gateway, which help control how traffic moves inside and outside the VPC.

What is a subnet?

The answer is that a `subnet` is a smaller network inside a VPC that is used to organize resources, such as a public subnet for web servers or a private subnet for databases.

What is a route table?

The answer is that a `route table` is a set of rules that tells network traffic where to go. For example, it can send traffic to the internet through an `Internet Gateway`, traffic inside the VPC through the local route, and traffic to a private network through a VPN Gateway. Route tables control network paths.

What is a gateway?

The answer is that a `gateway` is a connection point between networks. In AWS, gateways help a VPC connect to the internet, another private network, or an on-premises network.

What is a Virtual Private Gateway?

The answer is that a `Virtual Private Gateway`, or `VGW`, is a gateway used to connect a VPC to another private network. It is often used with a VPN connection to connect a company’s on-premises network to an AWS VPC.

What is IPv4?

The answer is that `IPv4` is the older and most common IP address system. An example of an IPv4 address is `192.168.1.1`, and most common private network ranges use IPv4.

What is a CIDR block?

The answer is that a `CIDR block` is an IP address range that can be used by a VPC, subnet, or network. Examples include `10.0.0.0/16` and `10.0.1.0/24`.

What is an on-premises network?

The answer is that an `on-premises network` is a company’s physical network outside the cloud. It may include office buildings, routers, switches, servers, and computers, and it is managed by the company rather than AWS.

What is a flat network?

The answer is that a `flat network` is a simple network without strong separation between its different parts. Many resources may exist in the same network area, which provides less control than a properly designed VPC with subnets and routing.

What is a shared network?

The answer is that a `shared network` is a network used by many customers or systems together. `EC2-Classic` used this model, while a VPC gives each customer isolated network control.

What is network architecture?

The answer is that `network architecture` is the overall design of how a network is organized. It includes VPCs, subnets, route tables, gateways, security groups, CIDR blocks, and traffic flow. Good network architecture makes a system more secure and easier to manage.

What is a VPC component?

The answer is that a `VPC component` is a networking part located inside or attached to a VPC. Examples include a subnet, route table, Internet Gateway, NAT Gateway, security group, and Network ACL.

What is a private IP address?

The answer is that a `private IP address` is an internal IP address used for communication inside a private network such as a VPC. For example, `10.0.1.20` is a private IP address and is not directly reachable from the public internet.

What is Network Address Translation?

The answer is that `Network Address Translation`, or `NAT`, changes one IP address into another when traffic moves between networks. For example, when a private EC2 instance uses a NAT Gateway to access the internet, the internet sees the NAT Gateway’s public IP address instead of the instance’s private IP address.

What is outbound traffic?

The answer is that `outbound traffic` is traffic going out from a VPC to the internet or another network, such as traffic sent from an EC2 instance to the internet.

What is inbound traffic?

The answer is that `inbound traffic` is traffic coming into a VPC from the internet or another network, such as traffic sent from an internet user to a public web server.

What are bandwidth constraints?

The answer is that `bandwidth constraints` are limits on how much network traffic can pass through a resource or network path. These limits may affect the speed or volume of traffic.

What is a protocol?

The answer is that a `protocol` is a communication method that defines how computers communicate with each other. Examples include `HTTP`, `HTTPS`, `TCP`, `UDP`, `ICMP`, and `SSH`. In a common VPC design, the VPC may use `10.0.0.0/16`, with a public subnet such as `10.0.1.0/24` containing a web server and load balancer, and a private subnet such as `10.0.2.0/24` containing a backend server and database. An `Internet Gateway` allows the public subnet to access the internet, while a `NAT Gateway` allows the private subnet to access the internet safely. A `VPC` is a private network inside AWS, a `CIDR block` is its IP range, a `subnet` is a smaller network inside the VPC, and a `route table` controls where traffic goes. For production, you usually create a custom VPC instead of relying only on the default VPC.
