##### What does `Amazon VPC` mean?
`Amazon VPC` means `Amazon Virtual Private Cloud`.
##### What does Amazon VPC let you create?
Amazon VPC lets you create your own private, controlled, and secure network inside AWS.
##### What is an Amazon VPC similar to?
An Amazon VPC is similar to a network in a company data center.
##### What networking features can you control in a VPC?
You can control IP addresses, subnets, routing, gateways, and security.
##### What resources can run inside a VPC?
You can run EC2 servers, databases, load balancers, and containers inside a VPC.
##### What connections can you control in a VPC?
You can control how resources connect to each other and to the internet.
##### What came before Amazon VPC?
Amazon VPC came after Amazon EC2.
##### What networking models did AWS use in the past?
AWS used two networking models called `EC2-Classic` and `EC2-VPC`.
##### What was `EC2-Classic`?
`EC2-Classic` was the old AWS networking model.
##### How did resources run in `EC2-Classic`?
Resources used a shared, flat network instead of running inside a private VPC.
##### What is `EC2-VPC`?
`EC2-VPC` is the current AWS networking model.
##### How do resources run in `EC2-VPC`?
Resources run inside isolated virtual networks called VPCs.
##### What are the benefits of `EC2-VPC`?
`EC2-VPC` is more secure and gives you more control.
##### What is a `NAT Gateway`?
A `NAT Gateway` allows private resources to access the internet without allowing direct incoming connections from the internet.
##### How can a private EC2 instance use a `NAT Gateway`?
An EC2 instance in a private subnet can use a `NAT Gateway` to download software updates.
##### Can the internet directly reach an instance using a `NAT Gateway`?
No. People on the internet cannot directly reach the private instance.
##### What is `Amazon EC2`?
`Amazon EC2` is a service that lets you create and run virtual servers in AWS.
##### What is an EC2 instance?
An EC2 instance is like a server in the cloud.
##### What can you install on an EC2 instance?
You can install applications, databases, or backend services on it.
##### What is a `shared network`?
A `shared network` is a network used by many customers or systems together.
##### Which AWS networking model used a shared network?
`EC2-Classic` used a shared network.
##### How is a VPC different from a shared network?
A VPC gives each customer isolated network control.
##### What is `internet-bound traffic`?
`Internet-bound traffic` is traffic going from your VPC to the internet.
##### How can a private EC2 instance send internet-bound traffic?
A private EC2 instance can send traffic through a `NAT Gateway` to reach the internet.
##### What is a `public IP address`?
A `public IP address` is an IP address that can be used on the public internet.
##### When can people on the internet reach an EC2 instance?
They can reach it when the instance has a public IP address and the correct routing and security settings.
##### What is an `Elastic IP address`?
An `Elastic IP address` is a static public IP address that you can allocate in AWS.
##### How is an `Elastic IP address` different from a normal public IP address?
Unlike a normal public IP address, an `Elastic IP address` can remain the same.
##### What resources can use an `Elastic IP address`?
You can attach it to an EC2 instance or a `NAT Gateway`.
##### What is `Network Address Translation`?
`Network Address Translation`, or `NAT`, changes one IP address into another when traffic moves between networks.
##### What IP address does the internet see when a private instance uses a `NAT Gateway`?
The internet sees the `NAT Gateway`’s public IP address instead of the instance’s private IP address.
##### What is `outbound traffic`?
`Outbound traffic` is traffic going out from your VPC to the internet or another network.
##### What is an example of outbound traffic?
Traffic sent from an EC2 instance to the internet is outbound traffic.
##### What is a `NAT Instance`?
A `NAT Instance` is an EC2 instance that is manually configured to perform NAT.
##### Who manages a `NAT Instance`?
You manage a `NAT Instance` yourself.
##### What is an advantage of a `NAT Instance`?
It gives you more control than a `NAT Gateway`.
##### What is a disadvantage of a `NAT Instance`?
It requires more maintenance than a `NAT Gateway`.
