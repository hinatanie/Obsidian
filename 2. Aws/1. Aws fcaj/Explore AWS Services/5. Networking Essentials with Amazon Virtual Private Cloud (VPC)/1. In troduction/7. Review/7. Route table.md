##### What is the default VPC?
The default VPC is a VPC that AWS creates in each Region.
##### What CIDR block does the default VPC use?
The default VPC uses `172.31.0.0/16`.
##### What is the default VPC useful for?
The default VPC is useful for learning and quick testing.
##### Which VPC is usually used for production?
Production systems usually use a custom VPC.
##### Why is a custom VPC better for production?
A custom VPC gives better control over IP ranges, subnets, routing, gateways, security, and network architecture.
##### What are important VPC components?
Important VPC components include a subnet, route table, `Internet Gateway`, and `NAT Gateway`.
##### What do VPC components help control?
They help control how traffic moves inside and outside the VPC.
##### What is a `route table`?
A `route table` is a set of rules that tells network traffic where to go.
##### Where can a route table send internet traffic?
A route table can send internet traffic to an `Internet Gateway`.
##### How does a route table handle traffic inside a VPC?
It can send traffic inside the VPC through the local route.
##### How can a route table send traffic to a private network?
It can send traffic to a private network through a VPN Gateway.
##### What do route tables control?
Route tables control network paths.
##### What is `network architecture`?
`Network architecture` is the overall design of how a network is organized.
##### What does network architecture include?
It includes VPCs, subnets, route tables, gateways, security groups, CIDR blocks, and traffic flow.
##### What are the benefits of good network architecture?
Good network architecture makes a system more secure and easier to manage.
##### What is a `VPC component`?
A `VPC component` is a networking part located inside or attached to a VPC.
##### What are examples of VPC components?
Examples include a subnet, route table, `Internet Gateway`, `NAT Gateway`, security group, and Network ACL.
##### What is a `protocol`?
A `protocol` is a communication method that defines how computers communicate with each other.
##### What are examples of protocols?
Examples include `HTTP`, `HTTPS`, `TCP`, `UDP`, `ICMP`, and `SSH`.
##### What CIDR block might a VPC use?
A VPC may use `10.0.0.0/16`.
##### What might a public subnet contain?
A public subnet such as `10.0.1.0/24` may contain a web server and a load balancer.
##### What might a private subnet contain?
A private subnet such as `10.0.2.0/24` may contain a backend server and a database.
##### What allows a public subnet to access the internet?
An `Internet Gateway` allows a public subnet to access the internet.
##### What allows a private subnet to access the internet safely?
A `NAT Gateway` allows a private subnet to access the internet safely.
##### What is a `VPC`?
A `VPC` is a private network inside AWS.
##### What is a `CIDR block`?
A `CIDR block` is the IP address range of a network.
##### What is a `subnet`?
A `subnet` is a smaller network inside a VPC.
##### What does a `route table` do?
A `route table` controls where network traffic goes.
##### Which VPC should you use for production?
For production, you usually create a custom VPC instead of relying only on the default VPC.
