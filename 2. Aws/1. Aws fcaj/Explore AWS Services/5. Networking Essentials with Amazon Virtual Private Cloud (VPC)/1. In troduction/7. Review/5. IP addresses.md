##### What does `Amazon VPC` mean?
`Amazon VPC` means `Amazon Virtual Private Cloud`.
##### What does Amazon VPC let you create?
Amazon VPC lets you create your own private, controlled, and secure network inside AWS.
##### What is an Amazon VPC similar to?
An Amazon VPC is similar to a network in a company data center.
##### What can you control in a VPC?
You can control IP addresses, subnets, routing, gateways, and security.
##### What resources can run inside a VPC?
A VPC can contain EC2 servers, databases, load balancers, and containers.
##### What connections can you control inside a VPC?
You can control how resources connect to each other and to the internet.
##### What is a `VPC CIDR block`?
A `VPC CIDR block` is the IP address range chosen when a VPC is created.
##### What is an example of a VPC CIDR block?
An example of a VPC CIDR block is `10.0.0.0/16`.
##### What does a VPC CIDR block determine?
It determines which private IP addresses can exist inside the VPC.
##### What is a `CIDR block`?
A `CIDR block` is an IP address range used by a VPC, subnet, or network.
##### What are examples of CIDR blocks?
Examples include `10.0.0.0/16` and `10.0.1.0/24`.
##### What address range does `10.0.0.0/16` allow?
`10.0.0.0/16` allows addresses in the `10.0.x.x` range.
##### What are example addresses in `10.0.0.0/16`?
Examples include `10.0.1.10`, `10.0.2.25`, and `10.0.100.50`.
##### What does a `/16` CIDR block provide?
A `/16` CIDR block provides a large number of IP addresses.
##### What does CIDR block size control?
CIDR block size controls how many IP addresses a VPC or subnet can have.
##### How many IP addresses does `/16` represent?
A `/16` CIDR block represents 65,536 IP addresses.
##### How many IP addresses does `/28` represent?
A `/28` CIDR block represents 16 IP addresses.
##### What does a smaller CIDR prefix number mean?
A smaller number after the `/` means a larger network.
##### What does a larger CIDR prefix number mean?
A larger number after the `/` means a smaller network.
##### What is `IPv4`?
`IPv4` is the older and most common IP address system.
##### What is an example of an IPv4 address?
An example of an IPv4 address is `192.168.1.1`.
##### Which IP system do most common private networks use?
Most common private network ranges use `IPv4`.
##### What is `IPv6`?
`IPv6` is a newer IP address system with a much larger address space.
##### How are IPv6 addresses different from IPv4 addresses?
IPv6 addresses are longer than IPv4 addresses.
##### What is a `primary CIDR block`?
A `primary CIDR block` is the main IP address range assigned to a VPC when it is created.
##### What is an example of a primary CIDR block?
`10.0.0.0/16` can be the main private IP range for a VPC.
##### What is `subnet sizing`?
`Subnet sizing` means choosing the size of a subnet by selecting a CIDR block.
##### How many IP addresses does `10.0.1.0/24` provide?
A subnet using `10.0.1.0/24` provides 256 IP addresses.
##### Why should subnet sizes be chosen carefully?
Subnet sizes should provide enough IP addresses for the resources that will use them.
##### What is a `private IP address`?
A `private IP address` is an internal address used for communication inside a private network such as a VPC.
##### What is an example of a private IP address?
`10.0.1.20` is an example of a private IP address.
##### Can a private IP address be reached directly from the internet?
No. A private IP address is not directly reachable from the public internet.
##### What is a `public IP address`?
A `public IP address` is an IP address that can be used on the public internet.
##### When can the internet reach an EC2 instance?
The internet can reach an EC2 instance when it has a public IP address and the correct routing and security settings.
##### What is an `Elastic IP address`?
An `Elastic IP address` is a static public IP address that you can allocate in AWS.
##### How is an Elastic IP different from a normal public IP address?
Unlike a normal public IP address, an Elastic IP can remain the same.
##### What resources can use an Elastic IP address?
An Elastic IP address can be attached to an EC2 instance or a `NAT Gateway`.
##### What is a `source IP`?
A `source IP` is the IP address from which network traffic originates.
##### What is an example of a source IP?
When a user sends traffic to a web server, the user’s IP address is the source IP.
##### What is `Network Address Translation`?
`Network Address Translation`, or `NAT`, changes one IP address into another when traffic moves between networks.
##### What IP address does the internet see when a private instance uses a NAT Gateway?
The internet sees the `NAT Gateway`’s public IP address instead of the instance’s private IP address.
