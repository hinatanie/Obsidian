##### What is a VPC CIDR block?
it determines which private IP addresses can exist inside your VPC.
##### What does `10.0.0.0/16` mean?
`10.0.0.0/16` allows your VPC to use IP addresses in the `10.0.x.x` range, such as `10.0.1.10`, `10.0.2.25`, and `10.0.100.50`.
##### Can you change the main VPC CIDR block later?
the main CIDR block cannot be changed after the VPC is created, so you should choose it carefully.
##### Why should VPC CIDR blocks not overlap?
your VPC CIDR block should not overlap with other networks, especially when you connect your VPC to a company office network, VPN network, or another VPC. Overlapping ranges make routing confusing
##### What is the default VPC?
AWS creates a default VPC in each Region with the CIDR block `172.31.0.0/16`.
##### What is a primary CIDR block?
a `primary CIDR block` is the main IP address range assigned to a VPC when it is created.
##### What is a CIDR block?
a `CIDR block` is an IP address range that can be used by a VPC, subnet, or network.
##### What is network architecture?
`network architecture` is the overall design of how a network is organized. It includes VPCs, subnets, route tables, gateways, security groups, CIDR blocks, and traffic flow. Good network architecture makes a system more secure and easier to manage.
##### What is a `protocol`?
A `protocol` is a communication method that defines how computers communicate with each other.
##### What are examples of protocols?
Examples include `HTTP`, `HTTPS`, `TCP`, `UDP`, `ICMP`, and `SSH`.
##### What is a `VPC`?
A `VPC` is a private network inside AWS.
##### What is a `CIDR block`?
A `CIDR block` defines the IP address range of a VPC.
##### What is a `subnet`?
A `subnet` is a smaller network inside a VPC.
##### What does a route table do?
A `route table` controls where network traffic goes.
##### What CIDR block might a VPC use?
A VPC may use `10.0.0.0/16`.
##### What might a public subnet contain?
A public subnet, such as `10.0.1.0/24`, may contain a web server and a load balancer.
##### What might a private subnet contain?
A private subnet, such as `10.0.2.0/24`, may contain a backend server and a database.
##### What does an `Internet Gateway` do?
An `Internet Gateway` allows the public subnet to access the internet.
##### What does a `NAT Gateway` do?
A `NAT Gateway` allows the private subnet to access the internet safely.
##### Which VPC should you use for production?
For production, you usually create a custom VPC instead of relying only on the default VPC.
