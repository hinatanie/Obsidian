##### What does `Amazon VPC` mean?
`Amazon VPC` means `Amazon Virtual Private Cloud`.
##### What does Amazon VPC let you create?
Amazon VPC lets you create your own private, controlled, and secure network inside AWS.
##### What is an Amazon VPC similar to?
An Amazon VPC is similar to a network in a company data center.
##### What can you control in a VPC?
You can control IP addresses, subnets, routing, gateways, and security.
##### What resources can run inside a VPC?
A VPC can contain EC2 servers, databases, load balancers, and containers.
##### What connections can you control inside a VPC?
You can control how resources connect to each other and to the internet.
##### What is a `subnet`?
A `subnet` is a smaller network inside a VPC that helps organize resources.
##### How can a VPC be divided into subnets?
A VPC using `10.0.0.0/16` can be divided into a public subnet using `10.0.1.0/24` and a private subnet using `10.0.2.0/24`.
##### What can a public subnet contain?
A public subnet can contain web servers.
##### What can a private subnet contain?
A private subnet can contain databases.
##### How is a subnet related to a VPC?
The VPC is the larger network, while subnets are smaller parts inside it.
##### What does CIDR block size control?
CIDR block size controls how many IP addresses a VPC can have.
##### How many IP addresses does `/16` represent?
A `/16` CIDR block represents 65,536 IP addresses.
##### How many IP addresses does `/28` represent?
A `/28` CIDR block represents 16 IP addresses.
##### What does a smaller CIDR prefix number mean?
A smaller number after the `/` means a larger network.
##### What does a larger CIDR prefix number mean?
A larger number after the `/` means a smaller network.
##### Why should VPC CIDR blocks not overlap?
Overlapping CIDR blocks make routing confusing between connected networks.
##### Which network ranges should a VPC CIDR block not overlap?
It should not overlap with a company office network, VPN network, another VPC, or any other connected network.
##### What happens if two connected networks use `10.0.0.0/16`?
The system may not know which network should receive traffic for an address such as `10.0.1.20`.
##### What CIDR blocks can avoid an overlap with `10.0.0.0/16`?
You can choose a different range, such as `10.10.0.0/16` or `172.16.0.0/16`.
##### What came before Amazon VPC?
Amazon VPC came after Amazon EC2.
##### What networking models did AWS use in the past?
AWS used `EC2-Classic` and `EC2-VPC`.
##### What was `EC2-Classic`?
`EC2-Classic` was the old AWS networking model.
##### How was networking shared in `EC2-Classic`?
Many AWS customers used a shared, flat network.
##### Did EC2 instances run inside private VPCs in `EC2-Classic`?
No. EC2 instances did not run inside each customer’s own private VPC.
##### What is `EC2-VPC`?
`EC2-VPC` is the current AWS networking model.
##### How do resources run in `EC2-VPC`?
Resources run inside isolated virtual networks called VPCs.
##### What are the benefits of `EC2-VPC`?
`EC2-VPC` is more secure and gives you more control.
##### What is the default VPC?
The default VPC is a VPC that AWS creates in each Region.
##### What CIDR block does the default VPC use?
The default VPC uses `172.31.0.0/16`.
##### What is the default VPC useful for?
The default VPC is useful for learning and quick testing.
##### Which VPC is usually used for production?
Production systems usually use a custom VPC.
##### Why is a custom VPC better for production?
A custom VPC gives better control over IP ranges, subnets, routing, gateways, security, and network architecture.
##### What are important VPC components?
Important VPC components include a subnet, route table, `Internet Gateway`, and `NAT Gateway`.
##### What do VPC components help control?
They help control how traffic moves inside and outside the VPC.
##### What is a `route table`?
A `route table` is a set of rules that tells network traffic where to go.
##### How can a route table send traffic to the internet?
It can send internet traffic through an `Internet Gateway`.
##### How does a route table handle traffic inside a VPC?
It can send traffic inside the VPC through the local route.
##### How can a route table send traffic to a private network?
It can send traffic to a private network through a VPN Gateway.
##### What do route tables control?
Route tables control network paths.
##### What is a `gateway`?
A `gateway` is a connection point between networks.
##### What can a gateway connect a VPC to?
A gateway can connect a VPC to the internet, another private network, or an on-premises network.
##### What is a `Virtual Private Gateway`?
A `Virtual Private Gateway`, or `VGW`, is a gateway used to connect a VPC to another private network.
##### What connection is often used with a `Virtual Private Gateway`?
A `Virtual Private Gateway` is often used with a VPN connection.
##### What networks can a `Virtual Private Gateway` connect?
It can connect a company’s on-premises network to an AWS VPC.
##### What is `IPv4`?
`IPv4` is the older and most common IP address system.
##### What is an example of an IPv4 address?
An example of an IPv4 address is `192.168.1.1`.
##### Which IP system do most common private networks use?
Most common private network ranges use `IPv4`.
##### What is a `CIDR block`?
A `CIDR block` is an IP address range used by a VPC, subnet, or network.
##### What are examples of CIDR blocks?
Examples include `10.0.0.0/16` and `10.0.1.0/24`.
##### What is an `on-premises network`?
An `on-premises network` is a company’s physical network outside the cloud.
##### What can an on-premises network contain?
It can contain office buildings, routers, switches, servers, and computers.
##### Who manages an on-premises network?
The company manages it rather than AWS.
##### What is a `flat network`?
A `flat network` is a simple network without strong separation between its different parts.
##### How are resources organized in a flat network?
Many resources may exist in the same network area.
##### Why does a flat network provide less control?
It provides less control than a properly designed VPC with subnets and routing.
##### What is a `shared network`?
A `shared network` is a network used by many customers or systems together.
##### Which AWS networking model used a shared network?
`EC2-Classic` used a shared network.
##### How is a VPC different from a shared network?
A VPC gives each customer isolated network control.
##### What is `network architecture`?
`Network architecture` is the overall design of how a network is organized.
##### What does network architecture include?
It includes VPCs, subnets, route tables, gateways, security groups, CIDR blocks, and traffic flow.
##### What are the benefits of good network architecture?
Good network architecture makes a system more secure and easier to manage.
##### What is a `VPC component`?
A `VPC component` is a networking part located inside or attached to a VPC.
##### What are examples of VPC components?
Examples include a subnet, route table, `Internet Gateway`, `NAT Gateway`, security group, and Network ACL.
##### What is a `private IP address`?
A `private IP address` is an internal IP address used for communication inside a private network such as a VPC.
##### What is an example of a private IP address?
`10.0.1.20` is an example of a private IP address.
##### Can a private IP address be reached directly from the internet?
No. A private IP address is not directly reachable from the public internet.
##### What is `Network Address Translation`?
`Network Address Translation`, or `NAT`, changes one IP address into another when traffic moves between networks.
##### What happens when a private EC2 instance uses a NAT Gateway?
The internet sees the `NAT Gateway`’s public IP address instead of the instance’s private IP address.
##### What is `outbound traffic`?
`Outbound traffic` is traffic going out from a VPC to the internet or another network.
##### What is an example of outbound traffic?
Traffic sent from an EC2 instance to the internet is outbound traffic.
##### What is `inbound traffic`?
`Inbound traffic` is traffic coming into a VPC from the internet or another network.
##### What is an example of inbound traffic?
Traffic sent from an internet user to a public web server is inbound traffic.
##### What are `bandwidth constraints`?
`Bandwidth constraints` are limits on how much network traffic can pass through a resource or network path.
##### How can bandwidth constraints affect traffic?
They can affect the speed or volume of network traffic.
##### What is a `protocol`?
A `protocol` is a communication method that defines how computers communicate with each other.
##### What are examples of protocols?
Examples include `HTTP`, `HTTPS`, `TCP`, `UDP`, `ICMP`, and `SSH`.
##### What CIDR block might a VPC use?
A VPC may use `10.0.0.0/16`.
##### What might a public subnet contain?
A public subnet such as `10.0.1.0/24` may contain a web server and a load balancer.
##### What might a private subnet contain?
A private subnet such as `10.0.2.0/24` may contain a backend server and a database.
##### What allows a public subnet to access the internet?
An `Internet Gateway` allows a public subnet to access the internet.
##### What allows a private subnet to access the internet safely?
A `NAT Gateway` allows a private subnet to access the internet safely.
##### What is a `VPC`?
A `VPC` is a private network inside AWS.
##### What is the IP range of a VPC called?
The IP range of a VPC is called a `CIDR block`.

A `route table` controls where network traffic goes.
