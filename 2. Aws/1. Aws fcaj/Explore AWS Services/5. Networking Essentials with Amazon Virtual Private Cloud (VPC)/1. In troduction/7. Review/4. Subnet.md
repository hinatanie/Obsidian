##### What does `Amazon VPC` mean?
`Amazon VPC` means `Amazon Virtual Private Cloud`.
##### What does Amazon VPC let you create?
Amazon VPC lets you create your own private, controlled, and secure network inside AWS.
##### What is an Amazon VPC similar to?
An Amazon VPC is similar to a network in a company data center.
##### What can you control in a VPC?
You can control IP addresses, subnets, routing, gateways, and security.
##### What resources can run inside a VPC?
A VPC can contain EC2 servers, databases, load balancers, and containers.
##### What connections can you control inside a VPC?
You can control how resources connect to each other and to the internet.
##### What is a `subnet`?
A `subnet` is a smaller network inside a VPC that helps organize resources.
##### How can a VPC be divided into subnets?
A VPC using `10.0.0.0/16` can be divided into a public subnet using `10.0.1.0/24` and a private subnet using `10.0.2.0/24`.
##### How is a subnet related to a VPC?
The VPC is the larger network, while subnets are smaller parts inside it.
##### What can subnets be used for?
A public subnet can contain web servers, while a private subnet can contain databases.
##### What is a `public subnet`?
A `public subnet` is a subnet that can connect to the internet through an `Internet Gateway`.
##### What resources usually run in a public subnet?
Public subnets are usually used for web servers, load balancers, and bastion hosts.
##### What is a `private subnet`?
A `private subnet` is a subnet that is not directly reachable from the public internet.
##### What resources usually run in a private subnet?
Private subnets are usually used for databases, private backend services, and internal application servers.
##### How can private resources access the internet?
Private resources can access the internet through a `NAT Gateway`.
##### Can the internet directly access private resources?
No. The internet cannot directly access resources in a private subnet.
##### What is an `Internet Gateway`?
An `Internet Gateway` is a VPC component that connects public resources in a VPC to the internet.
##### What traffic does an `Internet Gateway` allow?
It allows resources in public subnets to access the internet and allows internet traffic to reach public resources.
##### Why does a public EC2 web server need an `Internet Gateway`?
It needs an `Internet Gateway` to be reachable from the internet.
##### What is a `NAT Gateway`?
A `NAT Gateway` allows private resources to access the internet without allowing direct incoming connections from the internet.
##### How can a private EC2 instance use a `NAT Gateway`?
A private EC2 instance can use a `NAT Gateway` to download software updates.
##### Can people on the internet reach an instance through a `NAT Gateway`?
No. People on the internet cannot directly reach the private instance.
##### What is a `CIDR block`?
A `CIDR block` is an IP address range used by a VPC, subnet, or network.
##### What are examples of CIDR blocks?
Examples include `10.0.0.0/16` and `10.0.1.0/24`.
##### What is a `flat network`?
A `flat network` is a simple network without strong separation between its different parts.
##### How are resources organized in a flat network?
Many resources may exist in the same network area.
##### Why does a flat network provide less control?
It provides less control than a properly designed VPC with subnets and routing.
##### What is `subnet sizing`?
`Subnet sizing` means choosing the size of a subnet by selecting a CIDR block.
##### How many IP addresses does `10.0.1.0/24` provide?
`10.0.1.0/24` provides 256 IP addresses.
##### Why should subnet sizes be chosen carefully?
Subnet sizes should provide enough IP addresses for the resources that will use them.
##### What is `network architecture`?
`Network architecture` is the overall design of how a network is organized.
##### What does network architecture include?
It includes VPCs, subnets, route tables, gateways, security groups, CIDR blocks, and traffic flow.
##### What are the benefits of good network architecture?
Good network architecture makes a system more secure and easier to manage.
##### What is a `VPC component`?
A `VPC component` is a networking part located inside or attached to a VPC.
##### What are examples of VPC components?
Examples include a subnet, route table, `Internet Gateway`, `NAT Gateway`, security group, and Network ACL.
##### What is a `protocol`?
A `protocol` is a communication method that defines how computers communicate with each other.
##### What are examples of protocols?
Examples include `HTTP`, `HTTPS`, `TCP`, `UDP`, `ICMP`, and `SSH`.
##### What CIDR block might a VPC use?
A VPC may use `10.0.0.0/16`.
##### What might a public subnet contain?
A public subnet such as `10.0.1.0/24` may contain a web server and a load balancer.
##### What might a private subnet contain?
A private subnet such as `10.0.2.0/24` may contain a backend server and a database.
##### What does a `route table` do?
A `route table` controls where network traffic goes.
##### Which VPC should you use for production?
For production, you usually create a custom VPC instead of relying only on the default VPC.
