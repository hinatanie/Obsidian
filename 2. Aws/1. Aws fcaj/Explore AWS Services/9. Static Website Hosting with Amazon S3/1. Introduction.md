**Amazon S3** is an **object storage service**.
This means it stores data as objects instead of traditional files and folders like on your computer. An object can be an image, video, PDF, backup file, log file, website file, or any other type of data

Each object has a name, data, and metadata

**S3** is designed to scale on demand. 
This means you do not need to worry about buying storage hardware or predicting exactly how much storage you will need. 
You can store a small amount of data or a massive amount of data. and S3 can handle it

For example
```
a website can store images, videos, CSS, and JavaScript file in S3
A mobile app can upload user photos to S3
A company can use S3 to store backups
A data team can store raw data in S3 before analyzing it
IoT devices can send sensor data to S3 to storage and later processing
```

**S3 provides management feature** for you to organize your data and control who can access it
For example:
you can allow only specific users or applications to read or write objects in a bucket

**Permissions** can be managed at two levels
**Bucket-level permissions** control access to the while bucket.
**Object-level permissions** control access to specific files inside the bucket

---
**S3** has different storage classes. 
A storage class is like choosing the right type of storage based on how often you use the data

For example, if your website needs to load images every day, you should use **S3 Standard** 
Because it is designed for frequently accessed data. 
It gives fast access and high performance

If you have data that is not used often, such as old reports or backup files, you can use **S3 Standard-IA(Infrequent Access)**. The data is still available quickly, but the storage cost is usually lower than **S3 Standard**

For very old data that you only need to keep for long-term storage, you can use **S3 Glacier** or **S3 Glacier Deep Archive**. These are cheaper, but retrieving data can take longer

**S3** also provides strong security. 
**Data** can be **encrypted** while it is moving across the internet and while it is stored in AWS. 
You can control access using **IAM policies**, **bucket policies**, and **ACLs**

For example, you can allow only your backend server to upload files to a bucket. You can also block public access so normal users cannot directly open private files

**S3** also supports **management features**. With **versioning**, **S3** can keep old versions of files. This is useful if someone accidentally overwrites or deletes an object

For example:
```
logo.png version 1
logo.png version 2
logo.png version 3
```

**Lifecycle Management** helps reduce cost automatically. For example, you can create a rule like this
```
After 30 days, move object to Standard-IA
After 180 days, move object to Glacier
After 365 days, delete object
```

**AWS Amplify Hosing** is a managed AWS service for hosting static websites and web applications. It provides features such as HTTPS, deployment workflows, and global delivery

**Security** is protection of data, systems, and applications from unauthorized access or attacks

**Static website hosting** is hosting a website made of static files such as HTML, CSS, javascript, images, and videos. It does not require a backend server to generate pages dynamically

**HTTPS** is Hypertext Transfer Protocol Secure. A secure version of HTTP that encrypts communication between users and websites

**Global CDN** is Global Content Delivery Network. A system that stores and delivers website content from servers around the world to reduce latency

**CloudFront** is AWS's content delivery network service. It helps deliver content globally with low latency and high transfer speed

**Object storage** is a storage model where data is stored as objects. Each object usually includes the file data, metadata, and a unique key

**On-demand scalability** is the ability to increase or decrease capacity automatically or when needed, without buying hardware in advance

**Data availability** is ability to access data when needed

**Performance** is how fast and efficiently a service can store, retrieve, or process data

**Customers of all sizes** is individuals, startups, small businesses, large enterprises, and global organizations

**Store and protect data** is to save data safely and prevent loss, damage, or unauthorized access

**Data warehouse** is a system used to store large amounts of structured data for reporting and analysis

**IoT devices** is Internet of Things devices. Physical devices connected to the internet, such as sensors, cameras, and smart devices

**Scalability** is The ability of a system to handle increasing amounts of data, users, or traffic.
