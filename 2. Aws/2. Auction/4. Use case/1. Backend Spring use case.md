# Auction App MVP Use Case Design for Spring Boot
## Main architecture
```
Client request
   ↓
Controller
   ↓
Request DTO
   ↓
Service
   ↓
Repository
   ↓
Entity / Database
   ↓
Response DTO
```
```jsx
UC01 - Register user and create wallet
UC02 - Login user
UC03 - Deposit money
UC04 - Create auction session
UC05 - Create auction session rules
UC06 - Add auction item
UC07 - Publish auction session
UC08 - Open auction item
UC09 - Place bid
UC10 - Close auction item
UC11 - Winner pays
UC12 - Seller receives money
```
# UC01 - Register User
## API
```
POST /api/v1/auth/register
```
## Actor
```
Guest
```
## Goal
Guest tạo tài khoản mới. Sau khi tạo user thành công, hệ thống tự động tạo wallet mặc định cho user.
## Request DTO
```java
RegisterRequest
- email (không được để trống, đúng định dạng)
- password (không được để trống )
- fullName
```
## Response DTO
```java
UserResponse
- id
- email
- fullName
- role
- status
```
## Controller
```
AuthController
```
### Responsibility
```
- Nhận RegisterRequest và validate request body
- Gọi AuthService.register()
- Trả response cho client
- Trả về ResponseEntity.status(HttpStatus.CREATED).body(response)
```
## Service
```
AuthService
WalletService
```
### AuthService responsibility
```
1. Kiểm tra email đã tồn tại chưa, nếu chưa throw exception
2. Hash password.
3. Tạo User entity.
4. Lưu user vào database.
5. Gọi WalletService.createDefaultWallet(user).
6. Trả về AuthUserResponse.
```
### WalletService responsibility
```
1. Tạo wallet mặc định cho user.
2. balance = 0
3. lockedBalance = 0
4. currency = VND
5. status = ACTIVE
6. set User
```
## Repository
```
UserRepository
WalletRepository
```
### Needed methods
```java
UserRepository.existsByEmail(String email)
UserRepository.save(User user)
WalletRepository.save(Wallet wallet)
```
## Tables involved
```
users
wallets
```
## Validation
```
- Email không được trùng.
- Password không được rỗng.
- Role mặc định là USER.
- User status mặc định là ACTIVE.
- Wallet mặc định currency = VND.
- Wallet balance = 0.
- Wallet locked_balance = 0.
```
## Result
```
- users có user mới.
- wallets có wallet mới cho user.
```

```

```

## API
```
POST /api/v1/auction-items/{itemId}/bids
```
## Actor
```
BIDDER
```
## Goal
Bidder đặt giá cho item đang mở.
## Request DTO
```java
PlaceBidRequest
- amount
```
## Response DTO
```java
BidResponse
- id
- itemId
- bidderId
- amount
- status
- createdAt
```
## Controller
```
BidController
```
### Responsibility
```
- Lấy bidderId từ JWT
- Nhận itemId từ path variable
- Nhận amount từ request body
- Gọi BidService.placeBid(itemId, bidderId, request)
- Trả BidResponse
```
## Service
```
BidService
WalletService
```
### BidService responsibility
```
Method này bắt buộc dùng @Transactional.
1. Lấy bidder theo bidderId.
2. Kiểm tra bidder status = ACTIVE.
3. Kiểm tra bidder role = BIDDER.
4. Lấy wallet của bidder.
5. Kiểm tra wallet status = ACTIVE.
6. Lock auction item row bằng SELECT FOR UPDATE.
7. Kiểm tra item status = OPEN.
8. Lấy auction session.
9. Kiểm tra session status = ACTIVE.
10. Lấy auction session rule.
11. Kiểm tra amount >= currentPrice + minIncrement.
12. Kiểm tra wallet.balance >= amount.
13. Tìm bid hiện tại có status = WINNING.
14. Nếu có old winning bid:
    - Đổi old bid status = OUTBID.
    - Release tiền cho old bidder.
15. Tạo bid mới status = WINNING.
16. Hold tiền bidder mới:
    - wallet.balance -= amount
    - wallet.lockedBalance += amount
17. Tạo wallet transaction type = BID_HOLD.
18. Update auctionItem.currentPrice = amount.
19. Lưu tất cả thay đổi.
20. Commit transaction.
```
## Repository
```
UserRepository
WalletRepository
AuctionItemRepository
AuctionSessionRuleRepository
BidRepository
WalletTransactionRepository
```
### Needed methods
```java
UserRepository.findById(UUID userId)
WalletRepository.findByUserId(UUID userId)
WalletRepository.save(Wallet wallet)
AuctionItemRepository.findByIdForUpdate(UUID itemId)
AuctionItemRepository.save(AuctionItem item)
AuctionSessionRuleRepository.findBySessionId(UUID sessionId)
BidRepository.findFirstByItemIdAndStatus(UUID itemId, BidStatus status)
BidRepository.save(Bid bid)
WalletTransactionRepository.save(WalletTransaction transaction)
```
## Important Repository Query
```java

@Query("SELECT i FROM AuctionItem i WHERE i.id = :itemId")

```
## Tables involved
```
users
wallets
auction_sessions

wallet_transactions
```
## Validation
```
- User phải là BIDDER.
- User status phải ACTIVE.
- Wallet status phải ACTIVE.
- Item status phải OPEN.
- Session status phải ACTIVE.
- amount phải >= currentPrice + minIncrement.
- Wallet balance phải đủ tiền.
```
# UC10 - Close Auction Item
## API
```
PATCH /api/v1/auction-items/{itemId}/close
```
## Actor
```
SELLER
SYSTEM
```
## Goal
Đóng item và xác định winner.
## Response DTO
```java
AuctionItemResponse
```
## Controller
```
AuctionItemController
```
## Service
```
AuctionItemService
PaymentService
```
### Responsibility
```
Method này nên dùng @Transactional.
1. Lấy item theo itemId.
2. Kiểm tra item status = OPEN.
3. Lấy session.
4. Kiểm tra seller hiện tại là owner của session.
5. Tìm bid có status = WINNING.
6. Nếu có winning bid:
   - Set item status = SOLD.
   - Set winnerUserId = winningBid.bidderId.
   - Set finalPrice = winningBid.amount.
   - Set closedAt = now.
   - Gọi PaymentService.createPaymentForWinner(item).
7. Nếu không có bid:
   - Set item status = UNSOLD.
   - Set winnerUserId = null.
   - Set finalPrice = null.
   - Set closedAt = now.
8. Lưu item.
9. Trả response.
```
## Repository
```
AuctionItemRepository
BidRepository
PaymentRepository
```
### Needed methods
```java
AuctionItemRepository.findById(UUID itemId)
AuctionItemRepository.save(AuctionItem item)
BidRepository.findFirstByItemIdAndStatus(UUID itemId, BidStatus.WINNING)
PaymentRepository.save(Payment payment)
```


# note
Không nên tách các use case nội bộ như:
```
Create wallet
Release old bidder money
Seller receives money
Create payment for winner
```
thành API riêng ngay từ đầu.  
Trong Spring Boot, các flow này nên là private/internal service methods:
```java
WalletService.createDefaultWallet(user)
WalletService.releaseOldBidderMoney(oldBid)
WalletService.holdBidderMoney(wallet, amount)
PaymentService.createPaymentForWinner(item)
```
