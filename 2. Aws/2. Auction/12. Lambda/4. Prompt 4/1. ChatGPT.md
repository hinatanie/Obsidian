## Problem 5: I need your environment variable names
I do not need the secret values. I only need the variable names and what they are used for.
## Solution
Ask Cursor to generate:
```
docs/environment-variables.md
```
Use this prompt:
```
Analyze the backend, frontend, Docker Compose files, Dockerfiles, and environment example files.
Create:
docs/environment-variables.md
For every environment variable include:
1. Variable name.
2. Which application uses it.
3. File where it is referenced.
4. Whether it is required.
5. Example placeholder value.
6. Whether it is sensitive.
7. Whether AWS Lambda would also need it.
Never include real secrets, passwords, tokens, private keys, or production credentials.
Replace all sensitive values with placeholders such as:
DATABASE_URL=mysql+asyncmy://USER@HOST:3306/DATABASE  
JWT_SECRET_KEY=<secret>  
AWS_ACCESS_KEY_ID=<do-not-share>`
```
