## Problem 2: I need to understand every existing auction use case
## Solution
Ask Cursor to create:
```
docs/auction-use-cases.md
```
Use this prompt:
```
Analyze the existing auction backend and create:
docs/auction-use-cases.md
For every implemented auction use case, include:
1. Use case name.
2. API endpoint.
3. HTTP method.
4. Authentication requirement.
5. Required user role.
6. Request data.
7. Validation rules.
8. Database tables accessed.
9. Database records created or updated.
10. Response data.
11. Errors that may occur.
12. Whether the operation is synchronous or could be processed asynchronously.
13. Whether the operation could trigger an AWS Lambda function.
Include at least:
- Register
- Login
- Create auction session
- Start auction session
- End auction session
- Create auction item
- Place bid
- Viewer join
- Viewer leave
- Send notification
- Winner selection
- Payment-related operations, if implemented
- Image processing, if implemented
Use only actual code found in the project. Clearly mark features that do not exist yet.
```
This helps identify the best Lambda candidates.
