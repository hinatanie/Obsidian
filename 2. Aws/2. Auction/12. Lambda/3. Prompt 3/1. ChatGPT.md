Lambda may need to read or update auction records. I need the exact database schema before suggesting that.
## Solution
Ask Cursor to create:
```
docs/database-schema.md
```

```
Analyze all SQLAlchemy models and Alembic migrations and create:
docs/database-schema.md

1. Every database table.
2. Every column and data type.
3. Primary keys.
4. Foreign keys.
5. Unique constraints.
6. Indexes.
7. Relationships.
8. Enum values.
9. Cascade behavior.
10. Tables used by auction sessions, items, bids, users, notifications, payments, and images.
11. Current transaction handling.
12. Places where row locking is used.
13. Places where concurrent updates could occur.
```
