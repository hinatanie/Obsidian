# Recommended First Lambda Feature
For your Auction project, I recommend beginning with:
```
Automatically end auction sessions
```
The initial workflow would be:
```
EventBridge Scheduler
        ↓
Lambda runs every minute
        ↓
Find ACTIVE auction sessions whose end_time has passed
        ↓
Close all OPEN auction items
        ↓
Determine winning bids
        ↓
Mark items SOLD or UNSOLD
        ↓
Mark auction session ENDED
        ↓
Send result events to SQS
        ↓
Notification worker sends messages or emails
```
This is a better first Lambda exercise than moving your entire FastAPI backend into Lambda.
Your FastAPI backend can remain on EC2:
```
React
   ↓
Nginx
   ↓
FastAPI on EC2
   ↓
RDS MySQL
```
Lambda handles scheduled background work:
```
EventBridge
   ↓
Lambda
   ↓
Auction ending use case
   ↓
RDS MySQL
```
However, connecting Lambda directly to RDS requires careful VPC, security group, connection-pooling, transaction, and idempotency planning. I will design those parts after reviewing your project documents.
