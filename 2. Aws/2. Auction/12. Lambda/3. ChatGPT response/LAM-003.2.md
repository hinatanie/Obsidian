For **LAM-003.2**, you only need to create **one reusable helper** that every HTTP Lambda can call.
The goal is:
```
Lambda handler
   ↓
json_response(...)
   ↓
standard API Gateway response
```
Create this file:
```
backend/app/shared/http/response.py
```
Put this inside:
```
import json
from typing import Any
def json_response(
    status_code: int,
    data: Any,
    request_id: str | None = None,
    headers: dict[str, str] | None = None,
) -> dict:
    response_headers = {
        "Content-Type": "application/json",
    }
    if request_id:
        response_headers["X-Request-Id"] = request_id
    if headers:
        response_headers.update(headers)
    return {
        "statusCode": status_code,
        "headers": response_headers,
        "body": json.dumps(data, default=str),
    }
```
Now test it from your `backend` folder:
```
python -c "from app.shared.http.response import json_response; print(json_response(200, {'message':'ok'}, 'req-123'))"
```
Expected output should look roughly like:
```
{
    'statusCode': 200,
    'headers': {
        'Content-Type': 'application/json',
        'X-Request-Id': 'req-123'
    },
    'body': '{"message": "ok"}'
}
```
The important thing is that `body` is a **JSON string**, not a Python dictionary, because API Gateway expects the response body as a string.
Later, your handlers should use:
```
from app.shared.http.response import json_response
def lambda_handler(event, context):
    return json_response(
        status_code=200,
        data={
            "message": "auth api ready"
        },
        request_id="req-123",
    )
```
instead of manually writing:
```
return {
    "statusCode": 200,
    "body": ...
}
```
For now, **do not add CORS logic directly into `response.py` yet**. We will create that separately in **LAM-003.3**, then this helper can receive CORS headers through:
```
headers=...
```
That keeps responsibilities cleaner.
Your acceptance check for **LAM-003.2** is:
```
[ ] response.py exists
[ ] json_response() exists
[ ] statusCode is configurable
[ ] body is JSON serialized
[ ] Content-Type is application/json
[ ] request ID can be added
[ ] extra headers can be added
[ ] Lambda handlers can reuse this function
```
Once that test works, **LAM-003.2 is complete**.
