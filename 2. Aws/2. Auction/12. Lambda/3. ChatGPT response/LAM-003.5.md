For **LAM-003.5**, create one adapter that turns the raw API Gateway event into a clean Python object.
Use:
```
backend/app/shared/http/request.py
```
Put this inside:
```
from dataclasses import dataclass
from typing import Any
@dataclass(frozen=True)
class HttpRequest:
    method: str
    path: str
    path_parameters: dict[str, str]
    query_parameters: dict[str, str]
    headers: dict[str, str]
    body: str | None
    request_context: dict[str, Any]
def parse_api_gateway_event(event: dict) -> HttpRequest:
    request_context = event.get("requestContext") or {}
    http_context = request_context.get("http") or {}
    method = http_context.get("method") or event.get("httpMethod") or ""
    path = (
        event.get("rawPath")
        or event.get("path")
        or http_context.get("path")
        or ""
    )
    path_parameters = event.get("pathParameters") or {}
    query_parameters = (
        event.get("queryStringParameters")
        or {}
    )
    headers = {
        key.lower(): value
        for key, value in (event.get("headers") or {}).items()
    }
    body = event.get("body")
    return HttpRequest(
        method=method.upper(),
        path=path,
        path_parameters=path_parameters,
        query_parameters=query_parameters,
        headers=headers,
        body=body,
        request_context=request_context,
    )
```
This supports both common API Gateway shapes:
```
HTTP API v2
requestContext.http.method
rawPath
```
and older REST API style:
```
httpMethod
path
```
The result becomes something simple like:
```
HttpRequest(
    method="GET",
    path="/api/v1/auction-items/123",
    path_parameters={"itemId": "123"},
    query_parameters={"page": "1"},
    headers={"authorization": "Bearer xxx"},
    body=None,
    request_context={...},
)
```
So your Lambda handlers no longer need code like:
```
event["requestContext"]["http"]["method"]
event.get("queryStringParameters")
event.get("pathParameters")
```
everywhere.
Instead:
```
from app.shared.http.request import parse_api_gateway_event
def lambda_handler(event, context):
    request = parse_api_gateway_event(event)
    print(request.method)
    print(request.path)
```
Test it from `backend`:
```
python -c "from app.shared.http.request import parse_api_gateway_event; e={'rawPath':'/api/v1/items/123','requestContext':{'http':{'method':'GET'}},'pathParameters':{'itemId':'123'},'queryStringParameters':{'page':'1'},'headers':{'Authorization':'Bearer abc'}}; print(parse_api_gateway_event(e))"
```
Expected roughly:
```
HttpRequest(
    method='GET',
    path='/api/v1/items/123',
    path_parameters={'itemId': '123'},
    query_parameters={'page': '1'},
    headers={'authorization': 'Bearer abc'},
    body=None,
    request_context={'http': {'method': 'GET'}}
)
```
Also test missing optional values:
```
python -c "from app.shared.http.request import parse_api_gateway_event; print(parse_api_gateway_event({'requestContext':{'http':{'method':'POST'}},'rawPath':'/test'}))"
```
That should work without crashing.
A small useful improvement: because headers are normalized to lowercase, later you can reliably do:
```
authorization = request.headers.get("authorization")
origin = request.headers.get("origin")
```
instead of worrying whether API Gateway gives you:
```
Authorization
authorization
AUTHORIZATION
```
