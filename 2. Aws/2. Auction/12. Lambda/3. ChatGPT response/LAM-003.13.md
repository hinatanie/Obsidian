For **LAM-003.13**, keep it small: take the authenticated user from LAM-003.12 and check that their current database status is `ACTIVE`.
Use:
```
backend/app/shared/auth/authorization.py
```
Add this:
```
from app.shared.auth.authentication import AuthContext, AuthenticatedUser
from app.shared.http.errors import ForbiddenError
def require_active_user(
    auth_context: AuthContext,
) -> AuthenticatedUser:
    user = auth_context.user
    if user.status != "ACTIVE":
        raise ForbiddenError(
            "User account is not active."
        )
    return user
```
The flow is:
```
valid JWT
   ↓
authenticate_user()
   ↓
AuthContext
   ↓
require_active_user()
   ↓
ACTIVE?
 ↙      ↘
yes      no
 ↓        ↓
allow    403
```

