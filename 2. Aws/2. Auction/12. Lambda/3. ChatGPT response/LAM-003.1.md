# LAM-003.1 — Create the shared adapter structure
### Main problem
Eventually you will have:
```
auth_api
session_api
item_api
bid_api
admin_api
```
All of them need the same things:
```
JSON responses
CORS
request parsing
JWT authentication
validation
database sessions
error handling
```
We do **not** want this:
```
auth_api/
    JWT code
    response code
    database code
session_api/
    JWT code again
    response code again
    database code again
bid_api/
    JWT code again
    response code again
    database code again
```
Instead:
```
              app/shared
                  ↑
         reusable infrastructure
            ↗     ↑      ↖
       auth     session     bid
       Lambda    Lambda    Lambda
```

`database/` will handle:

sessions
