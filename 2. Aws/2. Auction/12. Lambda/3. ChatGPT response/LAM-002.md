# LAM-002.6 — Create the first `template.yaml`
Now create:
```
backend/template.yaml
```
Start with the SAM header:
```
AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31
Description: Auction Lambda backend
```
`Transform: AWS::Serverless-2016-10-31` tells CloudFormation that this is an AWS SAM template.
Then add a parameter:
```
Parameters:
  Environment:
    Type: String
    AllowedValues:
      - dev
      - prod
    Default: dev
```
Then define global Lambda settings:
```
Globals:
  Function:
    Runtime: python3.11
    Timeout: 30
    MemorySize: 256
    Environment:
      Variables:
        APP_ENV: !Ref Environment
```
Your first function can be:
```
Resources:
  AuthApiFunction:
    Type: AWS::Serverless::Function
    Properties:
      FunctionName: !Sub auction-auth-api-${Environment}
      CodeUri: .
      Handler: lambdas.auth_api.handler.lambda_handler
```
The relationship here is:
```
Handler:
lambdas.auth_api.handler.lambda_handler
        │        │          │
        │        │          └ function
        │        └ handler.py
        └ directory
```
AWS SAM supports Python Lambda functions through the function `Runtime`, `CodeUri`, and `Handler` properties.
