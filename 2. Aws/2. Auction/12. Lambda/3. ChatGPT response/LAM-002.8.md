At the top, make sure you have this:
```
Parameters:
  Environment:
    Type: String
    AllowedValues:
      - dev
      - prod
    Default: dev
```
The important part is:
```
AllowedValues:
  - dev
  - prod
```
That means SAM will only accept:
```
dev
prod
```
and reject something like:
```
test123
```

Also keep this:
```
Globals:
  Function:
    Environment:
      Variables:
        APP_ENV: !Ref Environment
```
That means inside your Python Lambda later:
```
import os
environment = os.environ["APP_ENV"]
```
would return:
```
dev
```
or:
```
prod
```
depending on deployment.
So the relationship is:
```
Environment parameter
        ↓
      dev/prod
        ↓
FunctionName
        ↓
auction-auth-api-dev
or
auction-auth-api-prod
```
and also:
```
Environment parameter
        ↓
APP_ENV
        ↓
Python Lambda
```
For example, in development:
```
auction-auth-api-dev
auction-session-api-dev
auction-item-api-dev
auction-bid-api-dev
auction-admin-api-dev
auction-realtime-dev
auction-session-worker-dev
auction-image-worker-dev
```

```
auction-auth-api-prod

auction-item-api-prod
auction-bid-api-prod

auction-realtime-prod
```
