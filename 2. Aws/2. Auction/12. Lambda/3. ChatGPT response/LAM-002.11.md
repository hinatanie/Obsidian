After that, SAM should create:

You should see folders for your Lambda resources, for example:
```
.aws-sam
└── build
    ├── AuthApiFunction
    ├── SessionApiFunction
    ├── ItemApiFunction
    ├── BidApiFunction
    ├── AdminApiFunction
    ├── RealtimeFunction
    ├── SessionWorkerFunction
    └── ImageWorkerFunction
```
Inside each one, because your `template.yaml` uses:
```
CodeUri: .
```
you should normally see packaged project files such as:
```
app/
lambdas/
```
That is important because your Lambda handlers will later import shared code from:
```
app/domain
app/application
app/infrastructure
app/shared
```
So the idea is:
```
backend/
├── app/
├── lambdas/
└── template.yaml
        ↓
     sam build
        ↓
.aws-sam/build/AuthApiFunction/
├── app/
└── lambdas/
```
This is what your assignment means by:
> Shared code can be packaged consistently.
