```text
+--------------------------------------------------+
| AI Agent application                             |
|                                                  |
| Your code                                        |
|                                                  |
| Python / JavaScript / Java                       |
|                                                  |
| Calls LLM                                        |
| Calls AWS tools                                  |
| Does investigation                               |
+--------------------------------------------------+
```
That program can run in different places.
```text
+--------------------------------------------------+
| EC2                                              |
|                                                  |
| A virtual server in AWS                          |
|                                                  |
| You install and run the Agent there              |
+--------------------------------------------------+
```
```text
+--------------------------------------------------+
| Lambda                                           |
|                                                  |
| Serverless function                              |
|                                                  |
| AWS runs the Agent code when triggered           |
+--------------------------------------------------+
```
```text
+--------------------------------------------------+
| ECS                                              |
|                                                  |
| Runs Docker containers                           |
|                                                  |
| Your Agent runs inside a container               |
+--------------------------------------------------+
```
```text
+--------------------------------------------------+
| Local Agent                                      |
|                                                  |
| Runs on your own laptop                          |
|                                                  |
| Example:                                         |
| Windows + Python                                 |
+--------------------------------------------------+
```
So visually:
```text
+----------------------+
| Your AI Agent code   |
+----------------------+
          |
          | must run somewhere
          v
+--------------------------------------+
| Choose one                           |
|                                      |
| EC2                                  |
| Lambda                               |
| ECS                                  |
| Your laptop                          |
+--------------------------------------+
```
For your first project, the easiest is probably:
```text
+--------------------------------------------------+
| Your Windows Laptop                              |
|                                                  |
| Python Agent                                     |
|                                                  |
| boto3                                            |
| OpenAI / another LLM                             |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| AWS Account                                      |
|                                                  |
| EC2                                              |
| CloudWatch                                       |
| CloudTrail                                       |
+--------------------------------------------------+
```

```text
EC2 / Lambda / ECS / Local Agent
```
I meant:
