AI Agent usually calls **APIs or tools that let it observe and interact with your cloud**.
```text
+--------------------------------------------------+
| AI Agent                                         |
|                                                  |
| Does NOT directly "see" AWS                      |
|                                                  |
| It needs tools                                   |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Tools                                            |
+--------------------------------------------------+
```
For AWS, common tools are:
```text
+--------------------------------------------------+
| AWS CLI                                          |
|                                                  |
| Example                                          |
| aws ec2 describe-instances                       |
| aws logs get-log-events                          |
| aws cloudtrail lookup-events                     |
+--------------------------------------------------+
```
```text
+--------------------------------------------------+
| AWS SDK                                          |
|                                                  |
| Python: boto3                                    |
| JavaScript: AWS SDK                              |
| Java: AWS SDK                                    |
|                                                  |
| Agent code calls AWS APIs programmatically       |
+--------------------------------------------------+
```
```text
+--------------------------------------------------+
| CloudWatch                                       |
|                                                  |
| Read metrics                                     |
| Read logs                                        |
| Check alarms                                     |
|                                                  |
| CPU                                              |
| latency                                          |
| errors                                           |
+--------------------------------------------------+
```
```text
+--------------------------------------------------+
| CloudTrail                                       |
|                                                  |
| Read AWS API history                             |
|                                                  |
| Who changed something?                           |
| What API was called?                             |
| When did it happen?                              |
+--------------------------------------------------+
```
```text
+--------------------------------------------------+
| EC2 API                                          |
|                                                  |
| DescribeInstances                                |
| DescribeSecurityGroups                           |
| DescribeRouteTables                              |
| DescribeSubnets                                  |
+--------------------------------------------------+
```
```text
+--------------------------------------------------+
| RDS API                                          |
|                                                  |
| DescribeDBInstances                              |
| DescribeEvents                                   |
| Read DB state                                    |
+--------------------------------------------------+
```
```text
+--------------------------------------------------+
| S3 API                                           |
|                                                  |
| ListObjects                                      |
| GetObject                                        |
| Read investigation artifacts                     |
+--------------------------------------------------+
```
And sometimes:
```text
+--------------------------------------------------+
| Kubernetes tools                                 |
|                                                  |
| kubectl                                          |
| Kubernetes API                                   |
|                                                  |
| Get pods                                         |
| Get events                                       |
| Get logs                                         |
+--------------------------------------------------+
```
or:
```text
+--------------------------------------------------+
| Database tools                                   |
|                                                  |
| SQL query                                        |
|                                                  |
| SELECT ...                                       |
| EXPLAIN ...                                      |
| performance query                                |
+--------------------------------------------------+
```
The important picture is:
```text
+----------------------+
| AI Agent             |
+----------------------+
          |
          v
+----------------------+
| Tool                 |
|                      |
| AWS CLI              |
| boto3                |
| CloudWatch API       |
| CloudTrail API       |
+----------------------+
          |
          v
+----------------------+
| AWS                  |
|                      |
| EC2                  |
| RDS                  |
| S3                   |
| VPC                  |
| IAM                  |
+----------------------+
```
For your **Prove It project**, I would start with only these 4:
```text
+--------------------------------------------------+
| Tool 1: EC2 API                                  |
| Inspect resources                                |
+--------------------------------------------------+
+--------------------------------------------------+
| Tool 2: CloudWatch API                           |
| Inspect metrics + logs                           |
+--------------------------------------------------+
+--------------------------------------------------+
| Tool 3: CloudTrail API                           |
| Inspect changes + API history                    |
+--------------------------------------------------+
+--------------------------------------------------+
| Tool 4: IAM / STS                                |
| Know who the Agent is                            |
+--------------------------------------------------+
```
That is enough to build a very good first investigation Agent.
