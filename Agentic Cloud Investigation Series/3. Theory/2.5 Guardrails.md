 Guardrails are basically **rules around how the Agent is allowed to behave**, even when it technically has access.
Think of it like this:
```text
+--------------------------------------------------+
| Permission                                       |
|                                                  |
| Can this API call succeed?                       |
+--------------------------------------------------+
+--------------------------------------------------+
| Guardrail                                        |
|                                                  |
| Should the Agent make this call in this task?    |
+--------------------------------------------------+
```
Example:
```text
+--------------------------------------------------+
| IAM Permission                                   |
|                                                  |
| Agent CAN call                                   |
| ec2:StopInstances                                |
+--------------------------------------------------+
```
But your investigation workflow may say:
```text
+--------------------------------------------------+
| Guardrail                                        |
|                                                  |
| During investigation:                            |
| NEVER stop or modify resources                   |
+--------------------------------------------------+
```
So the Agent may technically be capable of doing this:
```text
+--------------------------------------------------+
| EC2                                              |
|                                                  |
| StopInstances                                    |
+--------------------------------------------------+
```
But the workflow blocks it:
```text
+--------------------------------------------------+
| Agent                                            |
|                                                  |
| "I want to restart EC2"                          |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Guardrail check                                  |
|                                                  |
| Investigation mode = read-only                   |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| BLOCKED                                          |
|                                                  |
| Do not execute                                   |
+--------------------------------------------------+
```
The same idea applies to the Agent's answers.
Without guardrails:
```text
+--------------------------------------------------+
| Agent                                            |
|                                                  |
| "The database caused the outage."                |
+--------------------------------------------------+
```
Problem:
```text
+--------------------------------------------------+
| No proof                                         |
|                                                  |
| No metric                                        |
| No timestamp                                     |
| No resource ID                                   |
| No source                                        |
+--------------------------------------------------+
```
With guardrails:
```text
+--------------------------------------------------+
| Rule                                             |
|                                                  |
| Every conclusion MUST include evidence           |
+--------------------------------------------------+
```
Then the Agent has to produce something like:
```text
+--------------------------------------------------+
| Conclusion                                       |
|                                                  |
| RDS CPU saturation likely caused API latency     |
+--------------------------------------------------+
+--------------------------------------------------+
| Evidence                                         |
|                                                  |
| Resource                                         |
| db-prod-01                                       |
|                                                  |
| Metric                                           |
| CPUUtilization                                   |
|                                                  |
| Value                                            |
| 96%                                              |
|                                                  |
| Time                                             |
| 14:03 - 14:11                                    |
|                                                  |
| Source                                           |
| CloudWatch                                       |
+--------------------------------------------------+
```
The important part is this:
```text
+--------------------------------------------------+
| Guardrail 1                                      |
|                                                  |
| Read only                                        |
|                                                  |
| Prevent dangerous actions                        |
+--------------------------------------------------+
+--------------------------------------------------+
| Guardrail 2                                      |
|                                                  |
| Evidence required                                |
|                                                  |
| Prevent unsupported conclusions                  |
+--------------------------------------------------+
+--------------------------------------------------+
| Guardrail 3                                      |
|                                                  |
| Resource ID required                             |
|                                                  |
| Prevent vague answers                            |
+--------------------------------------------------+
+--------------------------------------------------+
| Guardrail 4                                      |
|                                                  |
| Timestamp required                               |
|                                                  |
| Connect evidence to incident timeline            |
+--------------------------------------------------+
+--------------------------------------------------+
| Guardrail 5                                      |
|                                                  |
| Source required                                  |
|                                                  |
| Show where the fact came from                    |
+--------------------------------------------------+
```
So guardrails protect two things:
```text
+--------------------------------------------------+
| ACTION SAFETY                                    |
|                                                  |
| What the Agent is allowed to do                  |
+--------------------------------------------------+
+--------------------------------------------------+
| ANSWER QUALITY                                   |
|                                                  |
| What the Agent is allowed to claim               |
+--------------------------------------------------+
```
The full picture:
```text
+--------------------------------------------------+
| User asks                                       |
|                                                  |
| "Why was production slow?"                       |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Agent investigates                               |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Guardrails                                       |
|                                                  |
| Read only                                        |
| No production changes                            |
| Evidence required                                |
| Resource ID required                             |
| Timestamp required                               |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Agent checks                                     |
|                                                  |
| EC2                                              |
| RDS                                              |
| CloudWatch                                       |
| CloudTrail                                       |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Final answer                                     |
|                                                  |
| Conclusion                                       |
| Evidence                                         |
| Resource                                         |
| Time                                             |
| Source                                           |
+--------------------------------------------------+
```
So the simplest way to remember it is:
```text
+--------------------------------------------------+
| Permissions                                      |
|                                                  |
| Technical power                                  |
|                                                  |
| "Can I do this?"                                 |
+--------------------------------------------------+
+--------------------------------------------------+
| Guardrails                                       |
|                                                  |
| Behavioral rules                                 |
|                                                  |
| "Am I allowed to do this in this situation?"     |
+--------------------------------------------------+
```
And in an investigation Agent, guardrails are there to make the Agent **safe and provable**, not just powerful.
