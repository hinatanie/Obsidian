Think of **identity = “who is making this AWS request?”**
```text
+--------------------------------------------------+
| AWS receives a request                           |
|                                                  |
| "Describe EC2 instances"                         |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| AWS asks                                         |
|                                                  |
| WHO are you?                                     |
+--------------------------------------------------+
```
If both human and Agent use the same admin credentials:
```text
+--------------------------------------------------+
| Shared Admin Credentials                         |
|                                                  |
| Human uses them                                  |
| AI Agent uses them                               |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| CloudTrail sees                                  |
|                                                  |
| admin-user                                       |
| admin-user                                       |
| admin-user                                       |
+--------------------------------------------------+
```
Now you have a problem:
```text
+--------------------------------------------------+
| CloudTrail log                                   |
|                                                  |
| 10:01  admin-user  DescribeInstances             |
| 10:02  admin-user  ModifySecurityGroup           |
| 10:03  admin-user  GetLogEvents                  |
+--------------------------------------------------+
              ?
Was 10:02 done by:
+----------------------+
| Human?               |
+----------------------+
or
+----------------------+
| AI Agent?            |
+----------------------+
```
You cannot clearly distinguish them.

---
The better design is to give each actor its own identity:
```text
+--------------------------------------------------+
| Human                                            |
|                                                  |
| identity: human-admin                            |
+--------------------------------------------------+
+--------------------------------------------------+
| AI Agent                                         |
|                                                  |
| identity: investigation-agent-role               |
+--------------------------------------------------+
+--------------------------------------------------+
| Deployment Pipeline                              |
|                                                  |
| identity: deployment-role                        |
+--------------------------------------------------+
```
Then AWS sees:
```text
+--------------------------------------------------+
| CloudTrail                                       |
|                                                  |
| 10:01 human-admin                                |
|       DescribeInstances                          |
|                                                  |
| 10:02 investigation-agent-role                   |
|       GetLogEvents                               |
|                                                  |
| 10:03 deployment-role                            |
|       UpdateFunctionCode                         |
+--------------------------------------------------+
```
Now you can immediately understand:
```text
+----------------------------------+
| human-admin                      |
|                                  |
| A HUMAN did this                 |
+----------------------------------+
+----------------------------------+
| investigation-agent-role         |
|                                  |
| THE AI AGENT did this            |
+----------------------------------+
+----------------------------------+
| deployment-role                  |
|                                  |
| CI/CD did this                   |
+----------------------------------+
```
## Why use an IAM Role for the Agent?
Because your Agent is usually a program running somewhere:
```text
+--------------------------------------------------+
| EC2 / Lambda / ECS / Local Agent                 |
|                                                  |
| AI Agent application                             |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Assume IAM Role                                  |
|                                                  |
| investigation-agent-role                         |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| AWS gives temporary credentials                  |
|                                                  |
| AccessKeyId                                      |
| SecretAccessKey                                  |
| SessionToken                                     |
|                                                  |
| expire automatically                             |
+--------------------------------------------------+
```
The important part is that you do **not** normally hard-code permanent AWS keys inside the Agent.
Bad:
```text
+--------------------------------------------------+
| agent.py                                         |
|                                                  |
| AWS_ACCESS_KEY = "AKIA......"                    |
| AWS_SECRET_KEY = "........"                      |
+--------------------------------------------------+
```
Good:
```text
+--------------------------------------------------+
| AI Agent                                         |
|                                                  |
| assumes                                          |
|                                                  |
| investigation-agent-role                         |
+--------------------------------------------------+
```
And the role itself has limited permissions:
```text
+--------------------------------------------------+
| investigation-agent-role                         |
|                                                  |
| CAN                                              |
|                                                  |
| Read CloudWatch                                  |
| Read CloudTrail                                  |
| Describe EC2                                     |
| Describe Security Groups                         |
|                                                  |
| CANNOT                                           |
|                                                  |
| Delete EC2                                       |
| Modify IAM                                       |
| Delete RDS                                       |
+--------------------------------------------------+
```
So **identity and permissions are different things**:
```text
+--------------------------------------------------+
| IDENTITY                                         |
|                                                  |
| "Who are you?"                                   |
|                                                  |
| investigation-agent-role                         |
+--------------------------------------------------+
+--------------------------------------------------+
| PERMISSION                                       |
|                                                  |
| "What are you allowed to do?"                    |
|                                                  |
| ec2:DescribeInstances                            |
| logs:GetLogEvents                                |
+--------------------------------------------------+
```
The full picture is:
```text
+---------------------------+
| AI Agent                  |
+---------------------------+
             |
             | assumes
             v
+---------------------------+
| IAM Role                  |
|                           |
| investigation-agent-role  |
+---------------------------+
             |
             | permissions
             v
+---------------------------+
| AWS                       |
|                           |
| EC2                       |
| CloudWatch                |
| CloudTrail                |
+---------------------------+
             |
             | records
             v
+---------------------------+
| CloudTrail                |
|                           |
| "This request came from   |
| investigation-agent-role" |
+---------------------------+
```
So the main reason for giving the Agent its **own identity** is:
```text
+--------------------------------------------------+
| You can answer                                   |
|                                                  |
| WHO did what?                                    |
|                                                  |
| Human?                                           |
| AI Agent?                                        |
| Deployment system?                               |
+--------------------------------------------------+
```
And that is essential when you later need to **prove what the Agent actually did**.
