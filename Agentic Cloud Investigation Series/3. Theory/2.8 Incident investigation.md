Here the key idea is: when the website becomes slow, ==the Agent== should **not guess one cause immediately**. It ==checks each important layer and collects evidence.==
```text
+------------------------------------------------------+
| Internet                                             |
+------------------------------------------------------+
                          |
                          v
+------------------------------------------------------+
| ALB                                                  |
| Receives user requests                               |
+------------------------------------------------------+
                          |
                          v
+------------------------------------------------------+
| EC2                                                  |
| Runs Spring Boot / FastAPI                           |
+------------------------------------------------------+
                          |
                          v
+------------------------------------------------------+
| RDS MySQL                                            |
| Stores and reads data                                |
+------------------------------------------------------+
```
---
## 1. Check ALB
==ALB is the first AWS component receiving HTTP requests.==
```text
+--------------------------------------------------+
| User                                             |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| ALB                                              |
+--------------------------------------------------+
```
==The Agent checks ALB==
```text
+-----------------------------+
| Request count               |
|                             |
| How many requests arrived?  |
+-----------------------------+
+-----------------------------+
| Response time               |
|                             |
| How long requests took      |
+-----------------------------+
+-----------------------------+
| 5xx errors                  |
|                             |
| Did backend requests fail?  |
+-----------------------------+
```
Example:
```text
+--------------------------------------------------+
| ALB at 14:05                                     |
|                                                  |
| Requests:       normal                           |
| Response time:  8 seconds   <-- BAD              |
| HTTP 5xx:       low                              |
+--------------------------------------------------+
```
This tells the Agent:
```text
+--------------------------------------------------+
| Users can reach ALB                              |
|                                                  |
| But backend responses are slow                   |
+--------------------------------------------------+
```
So it investigates deeper.

---
## 2. Check EC2
==Your application runs here.==
```text
+--------------------------------------------------+
| EC2                                              |
|                                                  |
| Spring Boot                                      |
| or                                               |
| FastAPI                                          |
+--------------------------------------------------+
```
==The Agent checks EC2==
```text
+----------------------+
| CPU                  |
|                      |
| Is CPU overloaded?   |
+----------------------+
+----------------------+
| Memory               |
|                      |
| Is RAM exhausted?    |
+----------------------+
+----------------------+
| Application logs     |
|                      |
| Errors?              |
| Timeouts?            |
| Exceptions?          |
+----------------------+
```
Example:
```text
+--------------------------------------------------+
| EC2 at 14:05                                     |
|                                                  |
| CPU:       30%                                   |
| Memory:    normal                                |
|                                                  |
| Logs:                                            |
|                                                  |
| DB query timeout                                 |
| DB query timeout                                 |
| DB query timeout                                 |
+--------------------------------------------------+
```
Now the Agent sees:
```text
+--------------------------------------------------+
| EC2 itself is probably NOT overloaded            |
|                                                  |
| But the application is waiting for database      |
+--------------------------------------------------+
```
So it goes one layer deeper.

---
## 3. Check RDS
```text
+--------------------------------------------------+
| EC2 application                                 |
+--------------------------------------------------+
                      |
                      | SQL queries
                      v
+--------------------------------------------------+
| RDS MySQL                                        |
+--------------------------------------------------+
```
==The Agent checks RDS:==
```text
+----------------------+
| CPU                  |
|                      |
| Is DB overloaded?    |
+----------------------+
+----------------------+
| Connections          |
|                      |
| Too many clients?    |
+----------------------+
+----------------------+
| Latency              |
|                      |
| Are queries slow?    |
+----------------------+
```
Suppose it finds:
```text
+--------------------------------------------------+
| RDS at 14:05                                     |
|                                                  |
| CPU:          96%       <-- BAD                  |
| Connections: 495 / 500  <-- BAD                  |
| Latency:      very high <-- BAD                  |
+--------------------------------------------------+
```
==Now we have stronger evidence.==
```text
+--------------------------------------------------+
| Website slow                                     |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| ALB response time high                           |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| EC2 logs show DB timeout                         |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| RDS CPU = 96%                                    |
| RDS connections almost full                      |
+--------------------------------------------------+
```
==The Agent can now say Database overload==
```text
+--------------------------------------------------+
| Likely problem                                   |
|                                                  |
| Database overload                                |
+--------------------------------------------------+
```
==But there is still another question:==
```text
+--------------------------------------------------+
| WHY did the database suddenly become overloaded? |
+--------------------------------------------------+
```
That is where CloudTrail becomes useful.

---
## 4. Check CloudTrail
CloudTrail answers questions like:
```text
+--------------------------------------------------+
| Who changed AWS?                                 |
|                                                  |
| What changed?                                    |
|                                                  |
| When?                                            |
+--------------------------------------------------+
```
Example:
```text
+--------------------------------------------------+
| CloudTrail                                       |
|                                                  |
| 14:01                                            |
|                                                  |
| ModifyDBInstance                                 |
|                                                  |
| db-prod-01                                       |
|                                                  |
| performed by: admin-user                         |
+--------------------------------------------------+
```
Or perhaps:
```text
+--------------------------------------------------+
| CloudTrail                                       |
|                                                  |
| No RDS configuration changes                     |
| around 14:05                                     |
+--------------------------------------------------+
```
That is also useful.
It tells you:
```text
+--------------------------------------------------+
| Database is overloaded                           |
|                                                  |
| BUT probably not because someone changed         |
| the RDS configuration at 14:05                   |
+--------------------------------------------------+
```
Then the Agent may need to investigate application queries.

# Put the evidence together
Imagine the Agent collected this:
```text
+--------------------------------------------------+
| ALB                                              |
|                                                  |
| Response time increased at 14:04                 |
+--------------------------------------------------+
+--------------------------------------------------+
| EC2                                              |
|                                                  |
| CPU normal                                       |
| DB timeout errors began at 14:04                 |
+--------------------------------------------------+
+--------------------------------------------------+
| RDS                                              |
|                                                  |
| CPU increased to 96% at 14:03                    |
| Connections reached 495                          |
+--------------------------------------------------+
+--------------------------------------------------+
| CloudTrail                                       |
|                                                  |
| No infrastructure changes around incident        |
+--------------------------------------------------+
```
Now the Agent can make a much better conclusion:
```text
+--------------------------------------------------+
| Conclusion                                       |
|                                                  |
| The website slowdown is strongly correlated      |
| with RDS saturation.                             |
|                                                  |
| RDS CPU reached 96% before application           |
| DB timeouts and ALB latency increased.           |
+--------------------------------------------------+
```
Notice the Agent did **not** just say:
```text
+--------------------------------------------------+
| "RDS is broken."                                 |
+--------------------------------------------------+
```
It built a chain:
```text
+-----------------------+
| 14:03                 |
|                       |
| RDS CPU = 96%         |
+-----------------------+
          |
          v
+-----------------------+
| 14:04                 |
|                       |
| DB timeouts           |
+-----------------------+
          |
          v
+-----------------------+
| 14:04                 |
|                       |
| ALB latency rises     |
+-----------------------+
          |
          v
+-----------------------+
| 14:05                 |
|                       |
| Users notice slowness |
+-----------------------+
```
That is **incident investigation**:
```text
+--------------------------------------------------+
| Observe                                          |
|                                                  |
| ALB                                              |
| EC2                                              |
| RDS                                              |
| CloudTrail                                       |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Collect evidence                                 |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Compare timestamps                               |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Find likely cause                                |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Produce conclusion WITH proof                    |
+--------------------------------------------------+
```
And that is exactly why an AI Agent can be useful: it can inspect many places quickly, but you still require it to show **what it saw and why it reached the conclusion**.
