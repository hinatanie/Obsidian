# 1. The main idea
```text
+--------------------------------------------------+
| Your Cloud Environment                           |
|                                                  |
| EC2                                              |
| RDS                                              |
| S3                                               |
| IAM                                              |
| VPC                                              |
| CloudWatch                                       |
|                                                  |
+--------------------------------------------------+
                       ^
                       |
                       |
+--------------------------------------------------+
| AI Agent                                         |
|                                                  |
| Can inspect cloud resources                      |
| Can call tools                                   |
| Can read logs                                    |
| Can answer questions                             |
+--------------------------------------------------+
```
The problem is:
```text
+--------------------------------------------------+
| AI Agent says:                                   |
|                                                  |
| "The EC2 instance caused the incident."          |
|                                                  |
| Confidence: 95%                                  |
+--------------------------------------------------+
                    BUT
+--------------------------------------------------+
| You ask:                                         |
|                                                  |
| "Show me the evidence."                          |
|                                                  |
| Which log?                                       |
| Which metric?                                    |
| Which API call?                                  |
| Which resource?                                  |
| Which timestamp?                                 |
+--------------------------------------------------+
```
That is what **Prove It** is about.
Not:
```text
+----------------------------------+
| Prompt Engineering               |
|                                  |
| Write better prompts             |
| Ask ChatGPT better questions     |
+----------------------------------+
```
But:
```text
+-----------------------------------------------+
| AI Agent working inside real cloud systems    |
|                                               |
| Identity                                      |
| Permissions                                   |
| Tools                                         |
| Logs                                          |
| Evidence                                      |
| Guardrails                                    |
| Investigation                                 |
+-----------------------------------------------+
```

# 2. Imagine the AI Agent as a new cloud engineer
```text
+--------------------------------------------------+
| New AI Cloud Engineer                            |
|                                                  |
| Name: Investigation Agent                        |
|                                                  |
| Can use:                                         |
|                                                  |
| AWS CLI                                          |
| CloudWatch                                       |
| CloudTrail                                       |
| EC2 API                                          |
| IAM API                                          |
| S3 API                                           |
+--------------------------------------------------+
```
You should NOT immediately give it this:
```text
+--------------------------------------------------+
| AI Agent                                         |
|                                                  |
| AdministratorAccess                              |
|                                                  |
| ec2:*                                            |
| s3:*                                             |
| iam:*                                            |
| rds:*                                            |
| lambda:*                                         |
| cloudformation:*                                 |
|                                                  |
| Can change EVERYTHING                            |
+--------------------------------------------------+
```
Because then this could happen:
```text
+--------------------------------------------------+
| Agent makes wrong assumption                     |
|                                                  |
|        ↓                                         |
|                                                  |
| Agent runs dangerous command                     |
|                                                  |
|        ↓                                         |
|                                                  |
| Deletes / changes production resource            |
+--------------------------------------------------+
```
Instead:
```text
+--------------------------------------------------+
| Investigation Agent                              |
|                                                  |
| READ ONLY                                        |
|                                                  |
| Describe EC2                                     |
| Read CloudWatch                                  |
| Read CloudTrail                                  |
| Describe Security Groups                         |
| Describe IAM                                     |
|                                                  |
| CANNOT                                           |
|                                                  |
| Delete EC2                                       |
| Modify SG                                        |
| Change IAM                                       |
+--------------------------------------------------+
```
This is **governance**.

# 3. Identity
The Agent should have its own identity.
Bad:
```text
+----------------------------------+
| Human Admin Account              |
|                                  |
| Admin credentials                |
|                                  |
|        shared with               |
|                                  |
| AI Agent                         |
+----------------------------------+
```
Good:
```text
+----------------------------------+
| Human                            |
|                                  |
| IAM User / SSO                   |
+----------------------------------+
+----------------------------------+
| AI Agent                         |
|                                  |
| Dedicated IAM Role               |
|                                  |
| investigation-agent-role         |
+----------------------------------+
```
Now AWS can know:
```text
+--------------------------------------------------+
| CloudTrail                                       |
|                                                  |
| Who called this API?                             |
|                                                  |
| human-admin                                      |
| investigation-agent-role                         |
| deployment-role                                  |
+--------------------------------------------------+
```
You can distinguish:
```text
+-----------------------+
| Human action          |
+-----------------------+
+-----------------------+
| Agent action          |
+-----------------------+
```

```text
+--------------------------------------------------+
```

# 5. Guardrails
Permissions say:
```text
"What CAN the Agent technically do?"
```
Guardrails say:
```text
"What SHOULD the Agent be allowed to do
during this workflow?"
```
Example:
```text
+--------------------------------------------------+
| Agent Guardrails                                 |
|                                                  |
| Rule 1                                           |
| Read-only investigation                          |
|                                                  |
| Rule 2                                           |
| Never modify production                          |
|                                                  |
| Rule 3                                           |
| Every conclusion needs evidence                  |
|                                                  |
| Rule 4                                           |
| Show exact resource ID                           |
|                                                  |
| Rule 5                                           |
| Show timestamp                                   |
+--------------------------------------------------+
```
So instead of:
```text
+--------------------------------------------------+
| Agent answer                                     |
|                                                  |
| "The database was overloaded."                   |
+--------------------------------------------------+
```
You want:
```text
+--------------------------------------------------+
| Agent conclusion                                 |
|                                                  |
| Database CPU saturation caused request latency   |
|                                                  |
+--------------------------------------------------+
+--------------------------------------------------+
| Evidence                                         |
|                                                  |
| RDS: db-prod-01                                  |
|                                                  |
| CPUUtilization                                   |
| 96%                                              |
|                                                  |
| 14:03 - 14:11                                    |
|                                                  |
| Source: CloudWatch                               |
+--------------------------------------------------+
```

```text
+--------------------------------------------------+

|                                                  |

+--------------------------------------------------+
                    |
                    v
+--------------------------------------------------+

                    |
                    v
+--------------------------------------------------+

+--------------------------------------------------+
```

```text
+--------------------------------------------------+
| Incident                                         |
|                                                  |
```

```text
+--------------------------------------------------+
                    |
                    v
+--------------------------------------------------+
| OBSERVE                                          |
|                                                  |
| Metrics                                          |
| Logs                                             |

                    |
                    v
+--------------------------------------------------+

+--------------------------------------------------+
                    |
                    v

+--------------------------------------------------+
                    |
                    v
+--------------------------------------------------+

+--------------------------------------------------+
```

# 9. Evidence chain
This is probably one of the most important things you will practice.
You do NOT want:
```text
+--------------------------------------------------+
| Conclusion                                       |
|                                                  |
| "Security group caused the outage."              |
+--------------------------------------------------+
```
You want an evidence chain:
```text
+--------------------------------------------------+
| Evidence 1                                       |
|                                                  |
| 14:02                                            |
| AuthorizeSecurityGroupIngress                    |
| CloudTrail                                       |
+--------------------------------------------------+
                       |
                       v
+--------------------------------------------------+
| Evidence 2                                       |
|                                                  |
| SG rule changed                                  |
| sg-012345                                        |
+--------------------------------------------------+
                       |
                       v
+--------------------------------------------------+
| Evidence 3                                       |
|                                                  |
| 14:03                                            |
| application DB connections dropped               |
+--------------------------------------------------+
                       |
                       v
+--------------------------------------------------+
| Evidence 4                                       |
|                                                  |
| 14:04                                            |
| ALB 5xx increased                                |
+--------------------------------------------------+
                       |
                       v
+--------------------------------------------------+
| Conclusion                                       |
|                                                  |
| SG change likely caused DB connectivity failure  |
+--------------------------------------------------+
```
Now you can defend the conclusion.

# 10. Timeline
Incident investigation often becomes a timeline.
```text
+----------+----------------------------------------+
| 14:01    | System healthy                         |
+----------+----------------------------------------+
+----------+----------------------------------------+
| 14:02    | Security Group modified                |
+----------+----------------------------------------+
+----------+----------------------------------------+
| 14:03    | DB connection errors begin             |
+----------+----------------------------------------+
+----------+----------------------------------------+
| 14:04    | API latency rises                      |
+----------+----------------------------------------+
+----------+----------------------------------------+
| 14:05    | ALB 5xx increases                      |
+----------+----------------------------------------+
+----------+----------------------------------------+
| 14:06    | Users report outage                    |
+----------+----------------------------------------+
```
This is much stronger than:
```text
"The problem started sometime after a network change."
```

# 11. Evidence vs assumption
You will probably need to train yourself to separate these.
```text
+--------------------------------------------------+
| FACT                                             |
|                                                  |
| RDS CPU = 97%                                    |
| at 14:05                                         |
|                                                  |
| Source: CloudWatch                               |
+--------------------------------------------------+
```
```text
+--------------------------------------------------+
| INFERENCE                                        |
|                                                  |
| High DB CPU probably increased query latency     |
+--------------------------------------------------+
```
```text
+--------------------------------------------------+
| UNKNOWN                                          |
|                                                  |
| Why CPU became high                              |
|                                                  |
| Need more evidence                               |
+--------------------------------------------------+
```
This separation is important for Agent systems.

# 13. Auditability
You should be able to inspect what the Agent did.
```text
+--------------------------------------------------+
| Agent Investigation Session                      |
|                                                  |
| Question                                         |
| Why was the API slow?                            |
|                                                  |
| Tool call #1                                     |
| DescribeInstances                                |
|                                                  |
| Tool call #2                                     |
| GetMetricData                                    |
|                                                  |
| Tool call #3                                     |
| LookupEvents                                     |
|                                                  |
| Tool call #4                                     |
| GetLogEvents                                     |
+--------------------------------------------------+
```
And later:
```text
+--------------------------------------------------+
| Audit Log                                        |
|                                                  |
| 10:01 Agent called CloudWatch                    |
| 10:02 Agent read EC2 state                       |
| 10:03 Agent queried CloudTrail                   |
| 10:04 Agent produced conclusion                  |
+--------------------------------------------------+
```
So someone can ask:
```text
"What exactly did this Agent inspect?"
```

```text
+--------------------------------------------------+
| AI Agent                                         |
|                                                  |
| Recommendation:                                 |
| modify security group                            |
+--------------------------------------------------+
                       |
                       v
+--------------------------------------------------+
| HUMAN APPROVAL                                   |
|                                                  |
| Approve?                                         |
|                                                  |
| YES / NO                                         |
+--------------------------------------------------+
                       |
                 if approved
                       |
                       v
+--------------------------------------------------+
| Execute change                                   |
+--------------------------------------------------+
```
Instead of:
```text
AI decides
   ↓
AI changes production
```

```text
+==============================================================+
                              ^
                              |
                              |
+==============================================================+
|                      AI AGENT                                |
|                                                              |
| Identity                                                     |
| investigation-agent-role                                     |
|                                                              |
| Permissions                                                  |
| read-only                                                    |
|                                                              |
| Tools                                                        |
| AWS APIs / CLI / SDK                                         |
|                                                              |
| Guardrails                                                   |
| no production modification                                   |
| evidence required                                            |
+==============================================================+
                              |
                              v
+==============================================================+
|                   INVESTIGATION                              |
|                                                              |
| Observation                                                  |
|      |                                                       |
|      v                                                       |
| Logs + Metrics + CloudTrail                                  |
|      |                                                       |
|      v                                                       |
| Evidence                                                     |
|      |                                                       |
|      v                                                       |
| Timeline                                                     |
|      |                                                       |
|      v                                                       |
| Hypothesis                                                   |
|      |                                                       |
|      v                                                       |
| Conclusion                                                   |
+==============================================================+
                              |
                              v
+==============================================================+
|                    PROVE IT                                  |
|                                                              |
| "Why do you believe this?"                                   |
|                                                              |
| Show:                                                        |
|                                                              |
| Resource ID                                                  |
| Timestamp                                                    |
| Metric                                                       |

```
So the core skill is basically:
```text
+--------------------------------------------------+
| Do NOT trust a confident AI answer               |
|                                                  |
| Trust a conclusion that has traceable evidence   |
+--------------------------------------------------+
```
And as a cloud engineer, you are learning to build an Agent that is **controlled, observable, auditable, and evidence-driven**.
