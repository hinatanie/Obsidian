Think of the **AI Agent application** as a normal software project that you write.
```text
+--------------------------------------------------+
| AI Agent application                             |
|                                                  |
| It is NOT just the LLM                           |
|                                                  |
| It is your program                               |
+--------------------------------------------------+
```
Inside that program:
```text
+--------------------------------------------------+
| Your Python code                                 |
|                                                  |
| agent.py                                         |
| tools.py                                         |
| aws_client.py                                    |
+--------------------------------------------------+
```
The program has 3 main parts:
```text
+--------------------------------------------------+
| 1. LLM                                           |
|                                                  |
| Used for reasoning                               |
|                                                  |
| "What should I check next?"                      |
+--------------------------------------------------+
+--------------------------------------------------+
| 2. AWS tools                                     |
|                                                  |
| Used to get real data                            |
|                                                  |
| EC2                                              |
| CloudWatch                                       |
| CloudTrail                                       |
+--------------------------------------------------+
+--------------------------------------------------+
| 3. Your Agent logic                              |
|                                                  |
| Connect LLM + AWS tools                          |
|                                                  |
| Decide what tool can be called                   |
| Validate results                                 |
| Build evidence                                   |
+--------------------------------------------------+
```
So the important picture is:
```text
+----------------------+
| LLM                  |
|                      |
| Thinks / reasons     |
+----------------------+
          ^
          |
          |
+----------------------+
| Your Agent code      |
|                      |
| Controls everything  |
+----------------------+
          |
          v
+----------------------+
| AWS tools            |
|                      |
| boto3                |
+----------------------+
          |
          v
+----------------------+
| AWS Account          |
+----------------------+
```
## What is `boto3`?
`boto3` is the Python library used to talk to AWS.
```text
+--------------------------------------------------+
| Python                                           |
|                                                  |
| boto3                                            |
|                                                  |
| = AWS SDK for Python                             |
+--------------------------------------------------+
```
For example, your Python Agent wants to know:
```text
"What EC2 instances exist?"
```
Your code can do something like:
```python
import boto3
ec2 = boto3.client("ec2")
response = ec2.describe_instances()
```
Visually:
```text
+--------------------------------------------------+
| Python Agent                                     |
|                                                  |
| boto3.client("ec2")                              |
+--------------------------------------------------+
                      |
                      | AWS API request
                      v
+--------------------------------------------------+
| AWS EC2 API                                      |
|                                                  |
| DescribeInstances                                |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Result                                           |
|                                                  |
| i-123                                            |
| running                                          |
| t3.micro                                         |
+--------------------------------------------------+
```
The LLM itself usually does **not** directly call AWS.
Instead:
```text
+--------------------------------------------------+
| LLM                                              |
|                                                  |
| "I need EC2 information."                        |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| Your Agent code                                  |
|                                                  |
| chooses tool:                                    |
| get_ec2_instances()                              |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| boto3                                            |
|                                                  |
| describe_instances()                             |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| AWS                                              |
+--------------------------------------------------+
```
Then AWS returns data:
```text
+--------------------------------------------------+
| AWS Result                                       |
|                                                  |
| Instance: i-123                                  |
| State: running                                   |
| CPU: not here yet                                |
+--------------------------------------------------+
```
Your Agent gives that result back to the LLM:
```text
+--------------------------------------------------+
| LLM receives                                     |
|                                                  |
| Instance i-123 is running                        |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| LLM thinks                                       |
|                                                  |
| "Now I should check CPU."                        |
+--------------------------------------------------+
```
Then another tool is called:
```text
+--------------------------------------------------+
| Agent code                                       |
|                                                  |
| get_cpu_metric()                                 |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| boto3 CloudWatch client                          |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| CloudWatch                                       |
|                                                  |
| CPUUtilization = 97%                             |
+--------------------------------------------------+
```
So an investigation can look like this:
```text
+--------------------------------------------------+
| User                                             |
|                                                  |
| "Why is my website slow?"                        |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| AI Agent                                         |
|                                                  |
| asks LLM to reason                               |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| LLM                                              |
|                                                  |
| "Check EC2 first."                               |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| boto3 -> EC2                                     |
|                                                  |
| Instance is running                              |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| LLM                                              |
|                                                  |
| "Check CPU."                                     |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| boto3 -> CloudWatch                              |
|                                                  |
| CPU = 97%                                        |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| LLM                                              |
|                                                  |
| "Check recent configuration changes."            |
+--------------------------------------------------+
                      |
                      v
+--------------------------------------------------+
| boto3 -> CloudTrail                              |
|                                                  |
| Find API events                                  |
+--------------------------------------------------+
```
And your laptop part means simply:
```text
+--------------------------------------------------+
| Your Windows Laptop                              |
|                                                  |
| This is where the Agent program is running       |
+--------------------------------------------------+
```
For example:
```text
C:\projects\cloud-agent\
```
could contain:
```text
+--------------------------------------------------+
| cloud-agent                                      |
|                                                  |
| agent.py                                         |
| tools.py                                         |
| requirements.txt                                 |
| .env                                             |
+--------------------------------------------------+
```
You run:
```text
python agent.py
```
Then:
```text
+--------------------------------------------------+
| Windows Laptop                                   |
|                                                  |
| Python process                                   |
|                                                  |
| agent.py                                         |
+--------------------------------------------------+
                      |
          +-----------+-----------+
          |                       |
          v                       v
+-------------------+    +-----------------------+
| LLM API           |    | AWS APIs              |
|                   |    |                       |
| OpenAI            |    | EC2                   |
| Gemini            |    | CloudWatch            |
| Claude            |    | CloudTrail            |
+-------------------+    +-----------------------+
```
The most important distinction is:
```text
+--------------------------------------------------+
| LLM                                              |
|                                                  |
| Brain                                            |
| Reasons about information                        |
+--------------------------------------------------+
+--------------------------------------------------+
| boto3                                            |
|                                                  |
| Hands / tools                                    |
| Gets real information from AWS                   |
+--------------------------------------------------+
+--------------------------------------------------+
| Your Agent code                                  |
|                                                  |
| Controller                                       |
| Connects the brain and the tools                 |
+--------------------------------------------------+
```
So when we say **“build an AI Agent”**, you are really building this whole system—not just sending a prompt to an LLM.
