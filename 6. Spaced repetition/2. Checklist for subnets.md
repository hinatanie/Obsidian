#flashcards  
What is a subnet?  
?  
+++  
#flashcards  
A `subnet` is a smaller network inside a `VPC`. It divides the VPC into smaller networks so AWS resources can be organized.  
?  
+++  
#flashcards  
What is the relationship between a VPC and its subnets?  
?  
+++  
#flashcards  
The `VPC` is the large network, while its `subnets` are smaller networks created inside it.  
?  
+++  
#flashcards  
How can the VPC CIDR block `10.0.0.0/16` be divided into smaller subnets?  
?  
+++  
#flashcards  
It can be divided into smaller CIDR blocks such as:
```text
10.0.1.0/24
10.0.2.0/24
10.0.3.0/24
```
?  
+++  
#flashcards  
Do subnets need to be inside the VPC CIDR block?  
?  
+++  
#flashcards  
Yes. Every subnet CIDR block must be contained inside the CIDR block of its VPC.  
?  
+++  
#flashcards  
Which subnets are valid inside a VPC with the CIDR block `10.0.0.0/16`?  
?  
+++  
#flashcards  
Valid examples include:
```text
10.0.1.0/24
10.0.2.0/24
10.0.3.0/24
```
They are valid because they are contained inside the `10.0.0.0/16` range.  
?  
+++  
#flashcards  
Can you create a subnet outside the VPC CIDR range?  
?  
+++  
#flashcards  
No. A subnet cannot use an IP address range that is outside its VPC CIDR block.  
?  
+++  
#flashcards  
Why is `192.168.1.0/24` not a valid subnet for a VPC using `10.0.0.0/16`?  
?  
+++  
#flashcards  
It is invalid because `192.168.1.0/24` is outside the VPC's `10.0.0.0/16` IP address range.  
?  
+++  
#flashcards  
How many IP addresses does AWS reserve in every subnet?  
?  
+++  
#flashcards  
AWS reserves `5 IP addresses` in every subnet for internal networking purposes.  
?  
+++  
#flashcards  
Can AWS resources use every IP address in a subnet?  
?  
+++  
#flashcards  
No. AWS reserves 5 addresses, so only the remaining IP addresses can be assigned to resources.  
?  
+++  
#flashcards  
How many total IP addresses are in a `/28` subnet?  
?  
+++  
#flashcards  
A `/28` subnet contains:
```text
16 total IP addresses
```

An IPv4 address contains `32 bits`.
```
IPv4 address = 32 bits
```
The `/28` means:
```
28 bits identify the network
```

That leaves:

```
32 - 28 = 4 bits
```

Those remaining `4 bits` can change to create IP addresses inside the subnet.
?  
+++  
#flashcards  
How many usable IP addresses are available in an AWS `/28` subnet?  
?  
+++  
#flashcards  
An AWS `/28` subnet has `11 usable IP addresses`:
```text
16 total addresses - 5 AWS-reserved addresses = 11 usable addresses
```
?  
+++  
#flashcards  
Why can you not use all IP addresses in an AWS subnet?  
?  
+++  
#flashcards  
You cannot use all addresses because AWS reserves some of them for internal networking services.  
?  
+++  
#flashcards  
What purposes are the five AWS-reserved subnet IP addresses used for?  
?  
+++  
#flashcards  
AWS reserves them for:
```text
Network address
VPC router
DNS
Future AWS use
Broadcast address
```
?  
+++  
#flashcards  
What should you remember when planning the size of an AWS subnet?  
?  
+++  
#flashcards  
Always subtract the `5 IP addresses` reserved by AWS when calculating how many usable addresses the subnet provides.  
?  
+++  
#flashcards  
What determines whether a subnet is public or private?  
?  
+++  
#flashcards  
A subnet's `route table` determines whether it is public or private.  
?  
+++  
#flashcards  
Is a subnet automatically public or private when it is created?  
?  
+++  
#flashcards  
No. Its network access depends on the routes configured in its associated route table.  
?  
+++  
#flashcards  
What is a public subnet?  
?  
+++  
#flashcards  
A `public subnet` is a subnet whose route table contains a route to an `Internet Gateway`.  
?  
+++  
#flashcards  
What route usually makes a subnet public?  
?  
+++  
#flashcards  
A route like this usually makes the subnet public:
```text
0.0.0.0/0 → Internet Gateway
```
?  
+++  
#flashcards  
What does `0.0.0.0/0` mean in an IPv4 route?  
?  
+++  
#flashcards  
`0.0.0.0/0` represents all IPv4 destinations that are not matched by a more specific route.  
?  
+++  
#flashcards  
What does the route `0.0.0.0/0 → Internet Gateway` tell AWS to do?  
?  
+++  
#flashcards  
It tells AWS to send internet-bound IPv4 traffic to the `Internet Gateway`.  
?  
+++  
#flashcards  
What kind of resources usually go in a public subnet?  
?  
+++  
#flashcards  
A public subnet usually contains internet-facing resources such as:
```text
Web server
Load balancer
Bastion host
```
?  
+++





#flashcards  
Why are web servers, load balancers, and bastion hosts often placed in public subnets?  
?  
+++  
#flashcards  
They may need to receive connections or traffic from the public internet.  
?  
+++  
#flashcards  
What is a private subnet?  
?  
+++  
#flashcards  
A `private subnet` is a subnet that does not have a direct route to an `Internet Gateway`.  
?  
+++  
#flashcards  
Can the internet directly reach resources in a private subnet?  
?  
+++  
#flashcards  
Normally, no. Without a direct route to an Internet Gateway, internet users cannot directly initiate connections to those resources.  
?  
+++  
#flashcards  
What kind of resources usually go in a private subnet?  
?  
+++  
#flashcards  
A private subnet usually contains internal resources such as:
```text
Database
Backend server
Internal service
```
?  
+++  
#flashcards  
Why are databases and backend services usually placed in private subnets?  
?  
+++  
#flashcards  
They should not normally be exposed directly to the public internet.  
?  
+++  
#flashcards  
Can resources in a private subnet access the internet?  
?  
+++  
#flashcards  
Yes. They can access the internet indirectly through a `NAT Gateway`.  
?  
+++  
#flashcards  
What is the internet access path for a private subnet using a NAT Gateway?  
?  
+++  
#flashcards  
The traffic path is:
```text
Private subnet → NAT Gateway → Internet Gateway → Internet
```
?  
+++  
#flashcards  
Why would a private resource need internet access through a NAT Gateway?  
?  
+++  
#flashcards  
It may need to download software updates, install packages, or call an external API.  
?  
+++  
#flashcards  
Can internet users directly connect back to private resources through a NAT Gateway?  
?  
+++  
#flashcards  
No. A NAT Gateway allows private resources to initiate outbound internet connections, but it does not make them directly reachable from the internet.  
?

What is an Availability Zone?  
?  
+++  
#flashcards  
An `Availability Zone`, or `AZ`, is a separate data center area inside an AWS Region.  
?  
+++  
#flashcards  
What are examples of Availability Zones in the `ap-southeast-1` Region?  
?  
+++  
#flashcards  
Examples include:
```text
ap-southeast-1a
ap-southeast-1b
ap-southeast-1c
```
?  
+++  
#flashcards  
Why are Availability Zones separated from one another?  
?  
+++  
#flashcards  
They are separated so that a problem in one AZ does not necessarily affect the other AZs in the same Region.  
?  
+++  
#flashcards  
Why should an application use multiple Availability Zones?  
?  
+++  
#flashcards  
Using multiple AZs allows the application to continue running when one AZ experiences a failure or disruption.  
?  
+++  
#flashcards  
What can happen if all application resources are placed in only one Availability Zone?  
?  
+++  
#flashcards  
The entire application may become unavailable if that Availability Zone fails.  
?  
+++  
#flashcards  
What is a basic highly available subnet design across two Availability Zones?  
?  
+++  
#flashcards  
A basic design is:
```text
Public subnet in AZ 1
Public subnet in AZ 2
Private subnet in AZ 1
Private subnet in AZ 2
```
?  
+++  
#flashcards  
How can a VPC with CIDR block `10.0.0.0/16` be divided across two Availability Zones?  
?  
+++  
#flashcards  
One possible design is:
```text
VPC: 10.0.0.0/16
├── AZ 1
│   ├── Public subnet: 10.0.1.0/24
│   └── Private subnet: 10.0.2.0/24
│
└── AZ 2
    ├── Public subnet: 10.0.3.0/24
    └── Private subnet: 10.0.4.0/24
```
?  
+++  
#flashcards  
How does a multi-AZ subnet design improve availability?  
?  
+++  
#flashcards  
It spreads resources across separate Availability Zones, so resources in another AZ can continue operating if one AZ has a problem.  
?
