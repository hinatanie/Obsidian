#flashcards  
What does `10.0.0.0/16` mean?  
?  
+++  
#flashcards
```text
10.0.0.0/16
```
This means the VPC can use IP addresses from the `10.0.x.x` range.
For example:
```text
10.0.1.10
10.0.2.25
10.0.100.50
```
A `/16` CIDR block provides a large number of IP addresses.  
?  
+++  
#flashcards  
Can you change the main VPC CIDR block after creating the VPC?  
?  
+++  
#flashcards  
No. After you create the VPC, its main CIDR block cannot be changed, so you should choose it carefully.
For example, if you create the VPC with:
```text
10.0.0.0/16
```
That CIDR block becomes the primary IP range for the VPC.

#flashcards  
What is a subnet?  
?  
+++  
#flashcards  
A `subnet` is a smaller network inside a VPC. You divide a VPC into subnets to organize resources.
For example, you may create:
```text
Public subnet
Private subnet
```
A public subnet can be used for web servers. A private subnet can be used for databases.
The VPC is the large network, and the subnets are smaller parts inside that network.  
?  
+++  
#flashcards  
What is an example of a VPC and subnet design?  
?  
+++  
#flashcards  
A VPC may use:
```text
10.0.0.0/16
```
You can divide it into smaller subnets:
```text
10.0.1.0/24    Public subnet
10.0.2.0/24    Private subnet
```
The VPC is the large network, while the public and private subnets are smaller networks inside it.  
?

#flashcards  
What is a public subnet?  
?  
+++  
#flashcards  
A `public subnet` is a subnet that can connect to the internet through an `Internet Gateway`.
You usually place internet-facing resources in a public subnet, such as:
```text
Web server
Load balancer
Bastion host
```
?  
+++  
#flashcards  
What is a private subnet?  
?  
+++  
#flashcards  
A `private subnet` is a subnet that is not directly reachable from the public internet.
You usually place internal resources in a private subnet, such as:
```text
Database
Private backend service
Internal application server
```
Private resources can still access the internet through a `NAT Gateway`, but the internet cannot directly access those resources.

Does a VPC belong to one AWS Region?  
?  
+++  
#flashcards  
Yes. A VPC belongs to one AWS Region.
For example, if you create a VPC in the Singapore Region, it exists only in that Region.
You can create multiple VPCs in the same Region.

#flashcards  
What does CIDR block size control?  
?  
+++  
#flashcards  
The CIDR block size controls how many IP addresses a VPC can have.
For example:
```text
/16 means 65,536 IP addresses
/28 means 16 IP addresses
```
A smaller number after `/` means a bigger network. A bigger number after `/` means a smaller network.

#flashcards  
Why should VPC CIDR blocks not overlap?  
?  
+++  
#flashcards  
VPC CIDR blocks should not overlap with other networks because overlapping IP ranges make routing ambiguous when the networks are connected. The system may not know which network contains the destination IP address.  
?  
+++  
#flashcards  
What is an example of an overlapping CIDR problem?  
?  
+++  
#flashcards  
If a company office network and an AWS VPC both use `10.0.0.0/16`, traffic sent to an address such as `10.0.1.20` may be routed incorrectly because the system cannot clearly determine which network contains it.  
?  
+++  
#flashcards  
What CIDR blocks could be used to avoid overlapping with `10.0.0.0/16`?  
?  
+++  
#flashcards  
Possible non-overlapping CIDR blocks include:
```text
10.10.0.0/16
172.16.0.0/16
```

+++  
#flashcards

?  
+++  
#flashcards  
The default VPC is a VPC that AWS creates in each Region. It uses the following CIDR block:
```text
172.31.0.0/16
```
It is useful for learning and quick testing.

?  
+++  
#flashcards
