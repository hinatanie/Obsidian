##### Problem 1: An IPv4 address has four sections
##### Solution
An IPv4 address is divided into four numbers:
```
192 . 168 . 1 . 10
```
Each section is called an `octet`.
```
Octet 1: 192
Octet 2: 168
Octet 3: 1
Octet 4: 10
```
The word `octet` means a group of `8 bits`.
Therefore:
```
4 octets × 8 bits = 32 bits
```
##### Problem 2: What is the range of each part of an IPv4 address
##### Solution
A bit can contain only:
```
0 or 1
```
Eight bits produce:
```
2⁸ = 256 possible combinations
```
These combinations represent decimal values from:
```
0 to 255
```
For example:
```
00000000 = 0
00000001 = 1
11111111 = 255
```
That is why each part of an IPv4 address must be between `0` and `255`.


##### Problem 3: What does `/28` mean?
##### Solution
An IPv4 address contains `32 bits` which means 4x8
```
IPv4 address = 32 bits
```
The `/28` means:
```
28 bits identify the network
```
That leaves:
```
32 - 28 = 4 bits
```
Those remaining `4 bits` can change to create IP addresses inside the subnet.
##### Problem 2: How do 4 bits create 16 addresses?
##### Solution
Each bit has two possible values:
```
0 or 1
```
With 4 bits, the number of combinations is:
```
2 × 2 × 2 × 2 = 2⁴ = 16
```
The combinations range from:
```
0000
0001
0010
...
1111
```
So a `/28` subnet contains:
```
16 total IP addresses
```
##### Practical example
Suppose the subnet is:
```
10.0.0.0/28
```
Its addresses are:
```
10.0.0.0
10.0.0.1
10.0.0.2
10.0.0.3
10.0.0.4
10.0.0.5
10.0.0.6
10.0.0.7
10.0.0.8
10.0.0.9
10.0.0.10
10.0.0.11
10.0.0.12
10.0.0.13
10.0.0.14
10.0.0.15
```
That is exactly `16` addresses.
In AWS, `5` are reserved:
```
16 total - 5 reserved = 11 usable
```
##### Reusable rule
```
Total IP addresses = 2^(32 - CIDR prefix)
```
For `/28`:
```
2^(32 - 28)
= 2^4
= 16
```
The key idea is:
```
/28 leaves 4 bits available
4 bits create 16 combinations
Therefore, /28 contains 16 IP addresses
```

## Problem 1: What does `0.0.0.0/0` mean?
## Solution

`0.0.0.0/0` means:

```
Every IPv4 address
```

Examples:

```
8.8.8.8
142.250.72.14
1.1.1.1
```

So it acts as the **default route** for any destination that does not match a more specific route.

## Problem 2: What does `0.0.0.0/0 → Internet Gateway` mean?

## Solution

`→ Internet Gateway` means:

```
Send matching traffic to the Internet Gateway
```

Therefore:

```
0.0.0.0/0 → Internet Gateway
```

means:

```
For traffic going to any IPv4 destination outside the VPC,
send it to the Internet Gateway.
```
