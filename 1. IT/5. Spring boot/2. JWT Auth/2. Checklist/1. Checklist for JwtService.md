```
package com.example.backend.auth;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.security.Keys;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

import javax.crypto.SecretKey;
import java.util.Date;

@Service
public class JwtService {

    @Value("${jwt.secret}")
    private String secret;

    @Value("${jwt.expiration}")
    private long expiration;

    private SecretKey getSigningKey() {
        return Keys.hmacShaKeyFor(secret.getBytes());
    }

    public String generateToken(UserDetailsForToken user) {
        Date now = new Date();
        Date expiredAt = new Date(now.getTime() + expiration);

        return Jwts.builder()
                .subject(String.valueOf(user.getId()))
                .claim("username", user.getUsername())
                .claim("role", user.getRole())
                .issuedAt(now)
                .expiration(expiredAt)
                .signWith(getSigningKey())
                .compact();
    }

    public String extractUserId(String token) {
        return extractClaims(token).getSubject();
    }

    public Claims extractClaims(String token) {
        return Jwts.parser()
                .verifyWith(getSigningKey())
                .build()
                .parseSignedClaims(token)
                .getPayload();
    }

    public boolean isTokenValid(String token) {
        try {
            Claims claims = extractClaims(token);

            return claims.getExpiration().after(new Date());
        } catch (Exception e) {
            return false;
        }
    }
}
```
#### **What are Claims?**
`Claims` means the data inside `JWT payload`
Example `JWT payload`
```
{
	"sub": "1",
	"username": "john",
	"role": "USER",
	"iat": 1710000000,  
	"exp": 1710003600
}
```
#### **What is annotation @Service in a class?**.
`@Service` means `Spring` will create this object automatically and then 
you can inject it into another class
#### **What is annotation @Value before a property in a class?**.
It read value of key inside `"${}"` from file `application.properties` and then assign that value to the property.
Example:
```
@Value("${jwt.secret}")
private String secret;
```
This reads the value of `jwt.secret` from `applicaton.properties`
#### **What is secret key?**.
The `secret key` is used to sign and verify tokens.
#### **What is getSigningKey method used for?**.
```
private SecretKey getSigningKey(){
	return Keys.hmacShaKeyFor(secret.getBytes());
}
```
Convert the `secret key` from you `application.properties` into a `HMAC secret key object`, so `JWT` can use it to sign and verify tokens

`JWT` needs a key to sign the token
When you generate token
```
.signWith(getSigningKey())
```
When you verify token
```
.verifyWith(getSigningKey())
```
Same key must be used for both

```

#### **What is JWT Parser?**.
A `JWT parser` is a tool that reads, decodes, and evaluates `JSON Web Token`
The `Parser` splits the token into its three distinct parts (`Header`, `Payload`, and `Signature`) and decodes the `Base64Url strings` into readable JSON format
#### **How to build JWT parser**.
```
return Jwts.parser()
```
#### **With JWT parser, How i can parse a string `jwt` to a `payload`?**.

	.verifyWith(getSigningKey())

	.getPayload();
```
