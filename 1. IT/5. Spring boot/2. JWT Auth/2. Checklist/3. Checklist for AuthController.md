```
package com.example.backend.auth;

import com.example.backend.auth.dto.LoginRequest;
import com.example.backend.auth.dto.LoginResponse;
import lombok.RequiredArgsConstructor;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/v1/auth")
@RequiredArgsConstructor
public class AuthController {

    private final AuthService authService;

    @PostMapping("/login")
    public LoginResponse login(@RequestBody LoginRequest request) {
        return authService.login(request);
    }
}
```
#### **What is @RestController**.
Define a class as a REST API controller.
It means this class can receive HTTP requests and return JSON responses.
#### **What is @RequestMapping("/api/v1/auth")**.
Sets the `base URL` for all `APIs` inside this controller
Every endpoint in this controller starts with `/api/v1/auth`
So later
```
@PostMapping("/login")
```
becomes
```
/api/v1/auth/login
```
#### **What is @RequiredArgsConstructor?**.
This tell Lombok to generate a constructor for final fields
Because you have
```
private final AuthService authService;
```
Lombok creates
```
public AuthController(AuService authService){
	this.authService = authService;
}
```
This is called `constructor injection`

#### **How many method HTTP?**
@GetMapping("/users/{id}") is used to get data.
You can get all data or specified data
```
GET /api/v1/users
GET /api/v1/users/1
```
```
@GetMaping("/users/{id}")
public UserResponse getUser(@PathVariable Long id) {
	return userService.getUser(id);
}
```

@PostMapping("/login") is used to create data or send data to server
Example
```
POST /api/v1/auth/login
```
Meaning send username and password to login

```
POST /api/v1/users
```
Meaning create new user
```
@PostMapping("/users")
public UserResponse createUser(@RequestBody CreateUserRequest request) {
	return userService.createUser(request);
}
```

@PutMapping("/users/{id}") is used to replace/ update the whole object
```
PUT /api/v1/users/1
```
Meaning update all information of user id =1
```
@PutMapping("/users/{id}")
public UserResponse updateUser(
	@PathVariable Long id,
	@RequestBody UpdateUserRequest request
) {
	return userService.updateUser(id,request);
}
```

@PatchMapping("users/{id}/password") is used to update part of an object
```
PATCH /api/v1/users/1/password
```
Meaning only change password of user id = 1
```
@PatchMapping("/users/{id}/password")
public void changePassword(
	@PathVariable Long id,
	@RequestBody ChangePasswordRequest request
) {
	userService.changePassword(id, request);
}
```

@DeleteMapping("/users/{id}") is used to delete data
```
DELETE /api/v1/users/1
```
Meaning delete user id = 1
```
@DeleteMapping("/users/{id}")
public void deleteUser(@PathVariable Long id){
	userService.deleteUser(id);
}
```

#### **what is this @RequestBody?**.
`@RequestBody` means taking the `JSON data` from the `HTTP request body` and convert it into a `Java Object`

Frontend sends request HTTP with JSON 
```
{
	"username": "john",
	"password": "12345"
}
```
Spring Boot converts that JSON into this Java Object 
```
LoginRequest request
```
Then you can use
```
request.getUsername()
request.getPassword
```
#### **What is @PathVariable?**.
`@PathVariable` means getting data from `URL path`
```
@GetMapping("/users/{id}")
public UserResponse getUser(@PathVariable Long id){
	return userService.getUser(id);
}
```
means the URL has a variable named `id`
User sends request HTTP 
```
GET /api/v1/users/5
```
Spring will set id = 5

```
@PathVariable Long id
```
means taking `id` from the URL path
#### **What is @RequestParam?**.
`@RequestParam` means getting data from the query string
`Query string` is the part after `?` in the URL
Example URL
```
GET /api/v1/users?name=john
```
Here `name=john` is a query parameter
```
@GetMapping("/users")
public List<UserResponse> searchUser(@RequestParam String name) {
	return userService.searchUsers(name)
}
```
#### **When to use @PathVariable, when to use @RequestParam?**.
Use `@PathVariable` when you want one specific resource, for identity
Use `@RequestParam` when you want filtering, searching, sorting, or pagination, for `options/filtering`
