```
package com.example.backend.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;

@Configuration
public class PasswordConfig {

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}
```
#### **What is @Configuration?**.
`@Configuration` defines a class which contains `bean definitions`
#### **What is bean?**.
A `bean` means an object managed by Spring
```
@Bean
public PasswordEncoder passwordEncoder(){
	return new BCryptPasswordEncoder()
}
```
This tells Spring to create this object and store it in Spring container
So Spring creates one object 
```
new BCryptPasswordEncoder()
```
and stores it as a `PasswordEncoder` bean
Later, other classes can use it by injection
```
private final PasswordEncoder passwordEncoder;
```
Spring sees that `AuthService` needs a `PasswordEncoder`, so Spring gives it the bean from `PasswordConfig`
#### **Why return PasswordEncoder, not BCryptPasswordEncoder?**
```
public PasswordEncoder passwordEncoder(){
	return new BCryptPasswordEncoder();
}
```

#### **What does BCrypt do?**.
`BCrypt` is used to hash passwords
```
String hashedPassword = passwordEncoder.encode(request.getPassword());
```
