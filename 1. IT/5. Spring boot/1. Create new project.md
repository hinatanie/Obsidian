##### **How to install required tools**  
Before creating a `Spring Boot` backend, you need to install these tools:
```text
Java
Maven
IntelliJ IDEA or VS Code
MySQL
```
##### **How to check Java**  
Run:
```bash
java -version
```
This checks if `Java` is installed on your computer.  
For `Spring Boot`, use `Java 17` or later.
##### **How to check Maven**  
Run:
```bash
mvn -version
```
This checks if `Maven` is installed on your computer.  
`Maven` is a build tool for Java projects.  
It is used to install dependencies, build the project, and run the project.
##### **How to create a project from Spring Initializr**  
Go to:
```text
https://start.spring.io
```
Choose:
```text
Project: Maven
Language: Java
Spring Boot: latest stable version
Group: com.example
Artifact: backend
Package name: com.example.backend
Packaging: Jar
Java: 17 or later
```
Then click:
```text
Generate
```
It will download a `.zip` file.
##### **What does `Group` mean?**
```text
Group: com.example
```
`Group` is usually your company, organization, or project domain written backwards.  
For learning, this is okay:
```text
com.example
```
For a real project, you may use something like:
```text
com.yourcompany
```
##### **What does `Artifact` mean?**
```text
Artifact: backend
```
`Artifact` is the project name.  
In this example, the project name is:
```text
backend
```
##### **What does `Package name` mean?**
```text
Package name: com.example.backend
```
This is the base Java package for your project.  
Your Java files will be inside this package.  
Example:
```text
src/main/java/com/example/backend
```
##### **What does `Packaging: Jar` mean?**
```text
Packaging: Jar
```
This means the project will be packaged as a `.jar` file.  
A `.jar` file can be run as a Java application.  
For most Spring Boot backend projects, `Jar` is the normal choice.
##### **What dependencies should you add?**  
Add these dependencies:
```text
Spring Web
Spring Data JPA
Spring Security
MySQL Driver
Lombok
Validation
Spring Boot DevTools
```
You can add `JWT` dependencies later in `pom.xml`.
##### **What does `Spring Web` do?**  
`Spring Web` lets you create REST APIs.  
For example:
```text
GET /api/hello
POST /api/login
GET /api/users
```
You need this for building backend APIs.
##### **What does `Spring Data JPA` do?**  
`Spring Data JPA` helps your Spring Boot app work with the database.  
It lets you create repositories like:
```java
UserRepository
ProductRepository
OrderRepository
```
These repositories are used to query and save data.
##### **What does `Spring Security` do?**  
`Spring Security` is used for authentication and authorization.  
For example:
```text
Login
Register
Password security
JWT authentication
Protect APIs
```
##### **What does `MySQL Driver` do?**  
`MySQL Driver` allows Spring Boot to connect to a `MySQL` database.  
Without it, your backend cannot talk to MySQL.
##### **What does `Lombok` do?**  
`Lombok` helps reduce repeated Java code.  
For example, instead of writing getters, setters, and constructors manually, you can use:
```java
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
```
##### **What does `Validation` do?**  
`Validation` is used to validate request data.  
For example:
```java
@NotBlank
@NotNull
@Email
@Size
```
This is useful when checking data from users.
##### **What does `Spring Boot DevTools` do?**  
`Spring Boot DevTools` improves the development experience.  
It can automatically restart the app when you change code.  
This is useful during development.
##### **How to open the project**  
After downloading the `.zip` file, extract it.  
Example folder:
```text
backend/
├── src/
├── pom.xml
└── mvnw
```
Then open the folder in `IntelliJ IDEA`.  
Open the folder that contains:
```text
pom.xml
```
##### **What is `pom.xml`?**
```text
pom.xml
```
`pom.xml` is the Maven configuration file.  
It contains:
```text
Project information
Dependencies
Build settings
Plugins
```
When you add a dependency, it usually goes inside `pom.xml`.
**Understand the default project structure**  
Default structure:
```text
src/main/java/com/example/backend
├── BackendApplication.java
```
`BackendApplication.java` is the main file.  
It starts the Spring Boot application.
**Recommended project structure**  
You should organize your project like this:
```text
src/main/java/com/example/backend
├── BackendApplication.java
├── controller
├── service
├── repository
├── entity
├── dto
└── config
```
This structure makes your project easier to understand.
##### **What is `controller`?**
```text
controller
```
`Controller` is for receiving HTTP requests.  
For example:
```text
GET /api/users
POST /api/login
DELETE /api/products/1
```
A controller receives requests from the frontend or client.
##### **What is `service`?**
```text
service
```
`Service` is for business logic.  
For example:
```text
Check login password
Create user
Calculate total price
Handle order logic
```
The controller should call the service.
##### **What is `repository`?**
```text
repository
```
`Repository` is for database access.  
For example:
```text
Find user by email
Save user
Delete product
Find all orders
```
The service usually calls the repository.
##### **What is `entity`?**
```text
entity
```
`Entity` is for database table mapping.  
For example, a `User` entity can become a `users` table in MySQL.
##### **What is `dto`?**
```text
dto
```
`DTO` means `Data Transfer Object`.  
It is used for request and response objects.  
For example:
```text
LoginRequest
RegisterRequest
UserResponse
```
DTOs help you control what data enters and leaves your API.
##### **What is `config`?**
```text
config
```
`Config` is for configuration files.  
For example:
```text
Security configuration
CORS configuration
JWT configuration
```
##### **How to run the Spring Boot project**  
Run:
```bash
mvn spring-boot:run
```
Or run this file in your IDE:
```text
BackendApplication.java
```
If successful, you will see something like:
```text
Tomcat started on port 8080
Started BackendApplication
```

```text
http://localhost:8080
```
##### **How to create the first test API**  
Create this folder:
```text
controller
```
Then create this file:
```text
HelloController.java
```
Put it here:
```text
src/main/java/com/example/backend/controller/HelloController.java
```
Add this code:
```java
package com.example.backend.controller;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;
@RestController
public class HelloController {
    @GetMapping("/api/hello")
    public String hello() {
        return "Hello Spring Boot Backend";
    }
}
```
##### **What does `@RestController` mean?**
```java
@RestController
```
`@RestController` tells Spring Boot that this class handles API requests.  
It returns data directly to the browser or frontend.
##### **What does `@GetMapping` mean?**
```java
@GetMapping("/api/hello")
```
`@GetMapping` creates a `GET` API route.  
This route is:
```text
/api/hello
```
So when you open this URL, Spring Boot runs the `hello()` method.
##### **How to test the first API**  
Run the project again:
```bash
mvn spring-boot:run
```
Open browser:
```text
http://localhost:8080/api/hello
```
Result:
```text
Hello Spring Boot Backend
```
##### **How to connect Spring Boot to MySQL**  
Open this file:
```text
src/main/resources/application.properties
```
Add:
```properties
spring.application.name=backend
server.port=8080
spring.datasource.url=jdbc:mysql://localhost:3306/backend_db
spring.datasource.username=root
spring.datasource.password=your_password
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
```
This config tells Spring Boot how to connect to MySQL.
##### **What does `spring.application.name` mean?**
```properties
spring.application.name=backend
```
This sets the application name.  
In this example, the app name is:
```text
backend
```
##### **What does `server.port` mean?**
```properties
server.port=8080
```
This tells Spring Boot to run on port:
```text
8080
```
So your backend URL is:
```text
http://localhost:8080
```
##### **What does `spring.datasource.url` mean?**
```properties
spring.datasource.url=jdbc:mysql://localhost:3306/backend_db
```
This is the MySQL connection URL.  
It means:
```text
Database type: MySQL
Host: localhost
Port: 3306
Database name: backend_db
```
So Spring Boot connects to this database:
```text
backend_db
```
##### **What does `spring.datasource.username` mean?**
```properties
spring.datasource.username=root
```
This is the MySQL username.  
For local development, using `root` is okay.  
For production, it is better to create a normal MySQL user with limited permissions.
##### **What does `spring.datasource.password` mean?**
```properties
spring.datasource.password=your_password
```
This is the password for the MySQL user.  
For real projects, do not write production passwords directly in `application.properties`.  
Use environment variables instead.
##### **What does `spring.jpa.hibernate.ddl-auto=update` mean?**
```properties
spring.jpa.hibernate.ddl-auto=update
```
This means Spring Boot can auto-create or update database tables from your `Entity` classes.  
For learning, `update` is okay.  
For real production, you usually use migration tools like:
```text
Flyway
Liquibase
```
##### **What does `spring.jpa.show-sql=true` mean?**
```properties
spring.jpa.show-sql=true
```
This tells Spring Boot to print SQL queries in the console.  
This is useful for learning and debugging.
##### **What does `spring.jpa.properties.hibernate.format_sql=true` mean?**
```properties
spring.jpa.properties.hibernate.format_sql=true
```
This makes the printed SQL easier to read.
##### **How to use environment variables in Spring Boot**  
In Spring Boot, you can keep sensitive values like database password and JWT secret in environment variables.  
Instead of writing:
```properties
spring.datasource.password=123456
```
You can write:
```properties
spring.datasource.password=${DB_PASSWORD}
```
Then Spring Boot reads the value from your environment variable.
##### **How to use fallback values**  
You can also write a fallback value:
```properties
spring.datasource.password=${DB_PASSWORD:123456}
```
This means:
```text
Use DB_PASSWORD if it exists
If DB_PASSWORD does not exist, use 123456
```
This is useful for local development.
##### **How to set environment variable in Windows PowerShell**  
Run:
```powershell
$env:DB_PASSWORD="123456"
```
This sets the environment variable for the current PowerShell session only.  
If you close the terminal, the variable disappears.
##### **How to check environment variable in Windows PowerShell**  
Run:
```powershell
echo $env:DB_PASSWORD
```
If it works, you should see:
```text
123456
```
##### **How to save environment variable permanently on Windows**  
Run:
```powershell
setx DB_PASSWORD "123456"
```
Then close PowerShell and open a new one.  
Check again:
```powershell
echo $env:DB_PASSWORD
```
##### **How to set environment variables in IntelliJ IDEA**  
Go to:
```text
Run → Edit Configurations → Environment variables
```
Add:
```text
DB_PASSWORD=123456
JWT_EXPIRATION=3600000
```
You can also add more variables, for example:
```text
DB_URL=jdbc:mysql://localhost:3306/backend_db
DB_USERNAME=root
JWT_SECRET=this-is-my-super-secret-key-for-jwt-login-system
```
##### **How to use environment variables in VS Code**  
Create or edit this file:
```text
.vscode/launch.json
```
Example:
```json
{
  "configurations": [
    {
      "type": "java",
      "name": "Spring Boot Backend",
      "request": "launch",

      "env": {
        "DB_URL": "jdbc:mysql://localhost:3306/backend_db",

        "JWT_EXPIRATION": "3600000"

```
Change `mainClass` to your real main class.  
For this project, it may be:
```text
com.example.backend.BackendApplication
```
##### **How to write `application.properties` using environment variables**  
Example:
```properties
spring.application.name=backend
server.port=8080
spring.datasource.url=${DB_URL:jdbc:mysql://localhost:3306/backend_db}
spring.datasource.username=${DB_USERNAME:root}
spring.datasource.password=${DB_PASSWORD:123456}
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
```
This is better because you can change database config without changing your code.
##### **How to create the first Entity**  
Create this folder:
```text
entity
```
Then create this file:
```text
User.java
```
Put it here:
```text
src/main/java/com/example/backend/entity/User.java
```
Add this code:
```java
package com.example.backend.entity;
import jakarta.persistence.*;
import lombok.*;
@Entity
@Table(name = "users")
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
@Builder
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String username;
    private String email;
    private String password;
}
```
##### **What does `@Entity` mean?**
```java
@Entity
```
`@Entity` tells Spring Boot that this class maps to a database table.  
So the `User` class can become a table in MySQL.
##### **What does `@Table` mean?**
```java
@Table(name = "users")
```
`@Table` sets the table name.  
In this example, the table name is:
```text
users
```
##### **What does `@Id` mean?**
```java
@Id
```
`@Id` marks the primary key of the table.  
In this example, the primary key is:
```java
private Long id;
```
##### **What does `@GeneratedValue` mean?**
```java
@GeneratedValue(strategy = GenerationType.IDENTITY)
```
This means MySQL will automatically generate the `id`.  
For example:
```text
1
2
3
4
```
##### **What do Lombok annotations mean?**
```java
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
@Builder
```
These are from `Lombok`.  
They help generate common Java code automatically.  
For example:
```text
Getters
Setters
Empty constructor
Full constructor
Builder pattern
```
So you do not need to write all of them manually.
