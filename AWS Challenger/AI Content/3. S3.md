S3 (Amazon Simple Storage Service) và Database (Cơ sở dữ liệu) là hai hệ thống lưu trữ dữ liệu với mục đích sử dụng hoàn toàn khác nhau. Điểm khác biệt cốt lõi nằm ở cấu trúc dữ liệu: ==S3 lưu trữ dữ liệu dạng tệp tin thô (hình ảnh, video, tài liệu), còn Database lưu trữ dữ liệu có cấu trúc để tìm kiếm và xử lý nhanh (thông tin người dùng, đơn hàng)==.
Dưới đây là bảng so sánh trực quan giữa S3 và Database:

|Tiêu chí|Amazon S3|Database (SQL / NoSQL)|
|---|---|---|
|Kiểu lưu trữ|Lưu trữ đối tượng (Object Storage). Dữ liệu là các file độc lập.|Lưu trữ có cấu trúc (Structured/Semi-structured). Dữ liệu dạng bảng (hàng/cột) hoặc JSON.|
|Loại dữ liệu|Dữ liệu không cấu trúc: Hình ảnh, video, file PDF, file backup, mã nguồn.|Dữ liệu giao dịch: Thông tin tài khoản, số dư, lịch sử mua hàng, log hệ thống.|
|Cách truy xuất|Sử dụng đường dẫn URL hoặc API (HTTP GET/PUT) để tải toàn bộ file.|Sử dụng ngôn ngữ truy vấn (SQL hoặc API của NoSQL) để tìm kiếm, lọc, sửa từng dòng dữ liệu.|
|Tốc độ phản hồi|Tốc độ cao khi tải file lớn, nhưng độ trễ (latency) tính bằng mili-giây cao hơn Database khi đọc/ghi liên tục.|Độ trễ cực thấp (vài mili-giây), tối ưu cho hàng nghìn lượt đọc/ghi dữ liệu nhỏ cùng một lúc.|
|Chi phí|Rất rẻ trên mỗi GB lưu trữ.|Đắt hơn nhiều so với S3 vì cần tài nguyên CPU/RAM lớn để xử lý truy vấn.|
## Cách chúng phối hợp hoạt động trong một ứng dụng
Trong thực tế, lập trình viên không bao giờ dùng một mình S3 hay một mình Database mà sẽ kết hợp cả hai:
- Ví dụ với ứng dụng Facebook:
    - Database (như MySQL hoặc DynamoDB) sẽ lưu: Tên của bạn, mật khẩu, danh sách bạn bè, và các dòng trạng thái (text). Trong đó, có một cột lưu đường dẫn đến ảnh đại diện của bạn (ví dụ: `https://amazonaws.com`).
    - Amazon S3 sẽ là nơi thực sự chứa file ảnh `user123-avatar.jpg` đó.
Khi bạn vào trang cá nhân, ứng dụng sẽ vào Database để lấy thông tin tên tuổi và lấy cái link ảnh, sau đó trình duyệt của bạn sẽ dựa vào link đó để tải bức ảnh từ S3 về hiển thị.
Bạn đang thiết kế tính năng lưu trữ cho ứng dụng của mình đúng không? Nếu bạn chia sẻ loại dữ liệu bạn cần lưu (ví dụ: file PDF hóa đơn, hay thông tin đăng nhập của khách hàng), tôi có thể tư vấn giải pháp lưu trữ tối ưu nhất.
