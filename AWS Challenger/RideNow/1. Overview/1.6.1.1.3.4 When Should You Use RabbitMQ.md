## 1.6.1.1.3.4 When Should You Use RabbitMQ?
- Background Processing: If a user uploads a heavy video file, your web server can drop a message into RabbitMQ for a background worker to encode it, allowing the website to stay fast and responsive for the user.
- Microservices Integration: Connecting different software applications written in different languages securely and asynchronously.
- Guaranteed Delivery: When it is absolutely critical that a message is successfully delivered and processed exactly once (like an order fulfillment system).
