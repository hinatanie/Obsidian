A **microservice** is a way to build one big system as **many small backend services**, where each service owns one specific business responsibility.
```text
+-----------------------+
| RideNow System        |
|                       |
|  +-----------------+  |
|  | User Service    |  |
|  | login, profile  |  |
|  +-----------------+  |
|                       |
|  +-----------------+  |
|  | Driver Service  |  |
|  | driver status   |  |
|  | location        |  |
|  +-----------------+  |
|                       |
|  +-----------------+  |
|  | Trip Service    |  |
|  | create trip     |  |
|  | trip status     |  |
|  +-----------------+  |
|                       |
|  +-----------------+  |
|  | Payment Service |  |
|  | payment/refund  |  |
|  +-----------------+  |
+-----------------------+
```
