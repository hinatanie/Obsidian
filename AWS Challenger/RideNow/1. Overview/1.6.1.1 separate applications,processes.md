The important point is: these are **not just different folders or classes**. They are usually **separate applications/processes**.  
For example:
```text
User Service
Spring Boot app
port 8081
database: user_db
```
```text
Trip Service
Spring Boot app
port 8082
database: trip_db
```
```text
Payment Service
Spring Boot app
port 8083
database: payment_db
```
They communicate through things like:
```text
HTTP / REST
gRPC
Kafka
RabbitMQ
```
For example, when a passenger books a ride:
```text
Passenger
    |
    v
Trip Service
    |
    | "find nearby drivers"
    v
Driver Service
    |
    | driver accepted
    v
Trip Service
    |
    | "trip completed"
    v
Payment Service
```
