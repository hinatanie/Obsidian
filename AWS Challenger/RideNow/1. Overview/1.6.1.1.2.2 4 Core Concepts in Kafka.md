## 4 Core Concepts in Kafka
- Producer: Applications that generate and send data (events or messages) into Kafka.
- Consumer: Applications that subscribe to and read those messages from Kafka to process them.
- Topic: A specific category or folder where Kafka organizes and stores messages. You can think of a Topic like a table in a database, but optimized for continuous data streams.
- Broker: A server running Kafka. Multiple brokers form a Kafka Cluster, which ensures high availability and prevents data loss by duplicating data across different servers.
