## 1.6.1.1.3.3 RabbitMQ vs. Apache Kafka
Since we just discussed Kafka, it helps to understand exactly when you would choose RabbitMQ over it:

|Feature|RabbitMQ|Apache Kafka|
|---|---|---|
|Design Intent|Traditional Smart Message Broker.|High-throughput Distributed Event Streaming.|
|Message Lifetime|Deleted automatically once a consumer acknowledges it.|Retained on disk for a set time (durable log), can be replayed.|
|Routing Power|High. Complex, dynamic routing using exchanges.|Low. Dumb broker, smart consumer; routing is simple based on topics.|
|Best Used For|Complex routing, transactional tasks, ensuring strict task delivery.|Log aggregation, big data analysis, high-throughput real-time streaming.|
