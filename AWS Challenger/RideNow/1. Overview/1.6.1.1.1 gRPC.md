
**gRPC** (Google Remote Procedure Call) is ==an **open-source, high-performance framework** developed by Google that allows software applications to communicate directly with one another, even if they are written in different languages or running on different operating systems==.

Instead of using traditional formats like JSON over REST, gRPC allows a client application to **directly call a method on a server application** on a different machine as if it were a local object, making it much easier to build connected, distributed systems.
