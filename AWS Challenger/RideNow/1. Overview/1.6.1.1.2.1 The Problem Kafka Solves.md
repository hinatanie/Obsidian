## The Problem Kafka Solves
In traditional systems, applications often connect directly to each other (Point-to-Point). As the number of applications grows, this network of connections becomes messy, fragile, and hard to maintain. If one system goes down or slows down, it can crash the others.  
Kafka solves this by acting as a centralized data pipeline. Applications simply stream their data into Kafka, and any other application that needs that data can pull it out independently.
