## 1.6.1.1.3.2 Core RabbitMQ Exchange Types (Flexible Routing)
Unlike simple message queues, RabbitMQ allows you to route messages in different ways using Exchanges:
- Direct: Delivers messages to a queue based on an exact matching routing key.
- Fanout: Copies and broadcasts the message to _all_ queues bound to it (perfect for publish-subscribe patterns).
- Topic: Routes messages based on wildcard matches (e.g., routing all messages starting with `europe.*` to a European server queue).
