#### 1. Show all check list in my project
```
ticktick project data $costProjectId
```

#### 2. Show all projects
```
ticktick project list
```

#### 3. Create task
```
# Create projects and capture their IDs
$costProject = ticktick project create `
    --name "AWS Cost Management" `
    --json | ConvertFrom-Json

$iamProject = ticktick project create `
    --name "IAM and Permissions" `
    --json | ConvertFrom-Json

$s3Project = ticktick project create `
    --name "S3 Image Storage" `
    --json | ConvertFrom-Json

$costProjectId = $costProject.id
$iamProjectId  = $iamProject.id
$s3ProjectId   = $s3Project.id


ticktick task create `
    --title '1. Create a $5 or $10 budget' `
    --project $costProjectId

ticktick task create `
    --title "1. Create alerts at 50%, 80%, and 100%" `
    --project $costProjectId
```

#### 4. Complete a task ticktick task complete <
```
list ID $ProjectId $TaskId
```

#### 5. Delete a task 
```
ticktick task delete $ProjectId $TaskId
```

#### 6. Set time to existing checklist
```
$taskId = "<TASK_ID>"

ticktick task update $taskId `
  --id $taskId `
  --project $projectId `
  --due-date "2026-08-02T09:00:00+0700"
```

#### 7. Create checklist with timeline
```
$projectId = "<AWS_ACCOUNT_AND_SECURITY_PROJECT_ID>"

ticktick task create --title "1. Create an AWS account" --project $projectId --due-date "2026-08-02T09:00:00+0700"

ticktick task create --title "2. Enable MFA for the root account" --project $projectId --due-date "2026-08-02T09:30:00+0700"

ticktick task create --title "3. Do not create an access key for the root account" --project $projectId --due-date "2026-08-02T10:00:00+0700"
```

#### 8. Create subtask
```
ticktick task create `

```
